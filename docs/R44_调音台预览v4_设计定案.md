## 一、固定音色：官方文档怎么说（本轮正面回答）

三种模式是**三份不同权重**，不是三个开关：

| 模式 | 官方输入 | 官方定位 | 我们 |
|---|---|---|---|
| VoiceDesign | `instruct` 必填，一段自然语言描述，`generate_voice_design(text, language, instruct)` | 从描述生成新声音；不需要预置音色编号，也不需要参考音频 [citation:7][citation:15] | **当前权重** |
| CustomVoice | `--speaker` 内置 9 个编号（Vivian / Serena / Uncle_Fu / Dylan / Eric / Ryan / Aiden / Ono_Anna / Sohee），1.7B 可另用 `instruct` 调语气情绪，0.6B 忽略指令 | 官方意义上的「固定音色」[citation:14][citation:6][citation:9] | 换权重才能用 |
| Base | `--voice-ref` 3 秒参考音频，提取说话人身份（音色/韵律/背景） | 声音克隆，官方称跨语言保持一致 [citation:5][citation:15] | 换权重才能用 |

**关键结论**：VoiceDesign **没有 speaker id、没有音色锁、没有参考音频入口** [citation:7][citation:15]。
用户已决定不换模型 → CustomVoice 的 9 个编号、Base 的参考音频在本软件里**不是可选项，界面不画开关**。

当前唯一能做的是：**身份描述全文 + 种子 + 9 项采样参数，三样全书不变**。
这是收敛漂移，**不等于官方承诺的跨段音色完全一致**。此句写进界面（③ 橙色提示），不藏。

**口径差异如实登记**：用户实际加载的是 `Serveurperso/Qwen3-TTS-GGUF` 的 voicedesign 权重；该 GGUF 仓库对
`base / customvoice` 两种模式的描述与官方 Python 版有出入 [citation:13][citation:11]。
当前 voicedesign 不受影响，差异只放进「高级 · 开发者」折叠区，普通视图不显示。

**入口双份**（用户要求「设置里面也要有，调音台里面」）：
- ② 设置页：「声音与音色」组常驻「调音台」「固定音色」两项，语言模型组沉到下方
- ③ 调音台：首屏「固定音色」行 → 官方三模式对照 → 当前能固定的三样

## 二、三态没有被绕混

对着 `ParamSpec.ParamKind` 与引擎参数结构逐项核过：

- **✅ 到引擎（12 项）**：9 项采样 + `instruct` 身份全文 + `lang=chinese` + `speaker=null`。
  默认值 `temperature 0.9 / top_k 50 / top_p 1.0 / repetition_penalty 1.05 / max_new_tokens 2048` [citation:10][citation:15]。
- **⚠️ 上层（可调，但模型只看得到字符串或 App 流程）**：12 维生成器、朗读档位/语速倾向/情绪强度、
  段间留白（WAV 合并插 48B/ms）、角色映射、预设。时机统一为**提交后对所有新任务生效**。
- **🔒 结构不可调（不画开关）**：`speed`/`pitch` 数值字段、并发数、24kHz mono、量化档、
  音色编号表、行内 `[gasp]` 标签。

**提交与试听彻底解耦**：`commitAll()` 只看有没有改动，**不依赖试听**；
`trial()` 不写配置、不进草稿、不改指纹。⑩ 差异屏明写「不需要先试听」。

## 三、别人家面板借鉴（R43 调研落地到图）

- 采样参数默认收起，声音描述放主位：官方 Playground 只有文本/语言/声音描述 + Generate [citation:14]；
  第三方面板用 `gr.Accordion("Quality Settings", open=False)`。
- **滑块 + 小数字框双模、每行一枚 ⟳ 单项恢复默认**，主/子说话者天然分组 —— ⑥ 已画。
- 分组改人话：主说话者（怎么说）/ 子说话者（怎么发声）/ 生成长度与确定性。
- 保存与预览分离：别人是「改完点保存，下次生成自动加载新配置」+ 独立播放器，**没有一家把保存挂在试听后面**。
- 12 维收进「帮我写描述」抽屉，默认不展开（⑤ 单独全展开画出来）。
- seed 两档分清：`⟳ 换一个` = 新的**固定**种子（仍可复现）；`-1` = 引擎随机 [citation:15]。

## 六、验收要点（批准后落代码时逐条挂断言）

- 任一编辑后顶部「待提交 N 项」准确，差异弹层逐项 `旧→新`
- 全页只剩「提交变更」一个生效动词；不试听也能提交
- 固定音色在设置页与调音台各有一个入口；普通视图不出现参数路径/文档坐标
- VoiceDesign 不画 speaker 选择、不画参考音频上传、不画 speed/pitch 开关
- 375px 下 12 维不横向滚、不碎字；dock 不压系统白条
- 唯一真值源、两态试听、9 项触达链路、4B 设置、prompt v2、native/JNI、缓存分桶、前台服务一行不动
