听本 · Tingben

本地离线把 txt / md / epub 变成能听的音频。端侧合成、正文不改、模型自己导入。
默认零联网；本机网关与跨网中继都要你手动开启。

装到手机

每次发版的安装包都叫 tingben-v版本号.apk，下载器里一眼分得清项目和版本。

去 Releases 下最新版 下载器订阅源（updates.atom）

覆盖安装保留已导入的模型与做好的音频。仅 arm64-v8a / Android 8.0+。

关于跨网中继

手机开着「设置 → 跨网中继」时，拿到地址与 Token 的人可以用浏览器或标准库脚本把文字发过来， 用这台手机调音台当前的预设合成，回传前在手机本地压成 M4A 再取回。

文字会经过你自己的 GitHub 私有仓库，合成完立刻删请求文件；Token 只给这一个仓库。 异步，几秒到十几秒。本页不收集任何 Token，也不提交文字——要点进「跨网语音中继」那一页。

严格意义的「零上传」在启用跨网中继时不成立；不开启时 App 无出站流量。
