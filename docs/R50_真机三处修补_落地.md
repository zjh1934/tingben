# R50 · 调音台真机三处修补：落地报告

**输入**：用户贴 `1.0.0+58` 真机两张截图，三条意见 —— ① 采样页「滑块和输入框需要调整」；
② 表演层「这一块应该有自定义输入块」；③「把设置页往下扒的时候，标签页为什么不跟着变」。
联动表见 `docs/R50_真机三处修补_联动表.md`。

## 一、先回答第 3 问：标签页为什么不跟着变

不是渲染 bug，是**只做了单向**。`AnchorBar.selected` 只读 `activeAnchor`，而这个状态只有两处赋值：
点 chip 的 `jumpTo()` 和身份卡里「固定音色是什么？」按钮。`scroll`（`rememberScrollState()`）变化时
没有任何回调回写，R49 的注释甚至写着「当前区由 MixerScreen 传入，不从滚动位置猜」。
所以只有「chip → 滚动」，缺了「滚动 → chip」。

本轮补上反向联动：`snapshotFlow { scroll.value to anchors.toMap() }` 按各区 `positionInParent().y`
反算当前区，点击跳转期间用 `jumpLock` 锁住防动画抖动，`finally` 保证释放；
没有列进锚点栏的区（试听 / 开关 / 诊断）归并到前一个可见锚点，不出现「全不高亮」。
「固定音色是什么？」也统一走 `jumpTo("fixedVoice")`，删掉第二套滚动逻辑。

## 二、第 1 问：滑块与输入框

真机截图里每行被一个带 `label = 精确值` 的 `OutlinedTextField` 撑到约 180px：
M3 默认最小高 56dp，数字框上下占满宽、滑块被压成一小段。

改成一行同一中线：**名字 78dp · 滑块 `weight(1f)` 28dp · 无标签数字框 72×38dp · ⟳ · ▾**。
高度靠 `Modifier.height(38.dp)` 强约束压掉 M3 默认 56dp 内高（不引 `BasicTextField`、不加依赖），
`isError` 越界红字、键盘 Done、滑块/数字框共用 `onInput` 全部保留；
「框里可填任意合法值 / 官方默认 / 字段 / 范围」移进展开的 ⓘ，不占行高。
`ParamSpec` 9 项 key / 默认值 / 范围、`onInput → draft.knobs` 链路一行未动。

## 三、第 2 问：表演层自定义输入块（必须真生效，不摆假开关）

`ChipRow` 的自定义框统一收成 **140×40dp 无标签小框**（12 维也用同一个，用户原话「小一点就可以」）；
表演层 5 项全部 `allowCustom = true`：

- **朗读档位 / 语速倾向 / 情绪强度**：三枚短语框 → `ProduceConfig.packExtra()` 合并成
  `朗读:…｜语速:…｜情绪:…` → `extraInstruct` → `styleInstruct()` 末尾拼进 instruct →
  提交后新合成生效；读回时 `unpackExtra()` 按前缀拆回三个框。选预设 chip 时 `clearPerfCustom()` 撤掉该项。
- **段间静音 / 失败重做**：数值框直接写 `gapMs` / `gateRetries`。**关键修复**：旧 `fromJson` 只认
  `GAP_OPTIONS` / `RETRY_OPTIONS` 白名单，自定义值提交后会被静默重置；改成范围校验
  （`0..5000ms`、`0..10`），`GAP_OPTIONS` 仍只作 chip 快捷值。
- `extraInstruct` 进 `audioStamp()`（改了语气会按既有机制作废旧 WAV）、`toJson()/fromJson()`；
  `MixerCommit.diff` 补「附加语气」一行，顶部「未提交 N 项」与差异弹层自动带上。
- `SCHEMA` 升 2，`fromJson` 宽容迁移：旧书签无该字段一律空串，绝不崩。
- 表演层仍是 ⚠️ **上层**徽标：能改，但模型只看得到拼好的文字或合并参数，不冒充 ✅ 到引擎字段。

界面态 `perfCustom` 在提交 / 丢弃 / 载入预设三处用 `syncPerfCustom()` 同步回已生效值，
不会出现「提交完了小框还留着编辑文字」或「丢弃后框与真值不一致」。

## 四、守恒

`MixerDraft.active()` / `MixerCommit.commit()` 唯一出口、唯一生效动词「提交变更」、两态试听、
9 项采样参数表、4B 设置、`prompt_zh.txt` v2、两条制作路径、`bucket()`、续跑书签、
`ProduceService`、native / JNI / `qt_tts_params`、Screen 枚举、`chromeOf`、抽屉壳、Manifest、
Gradle 依赖 —— 全部一行未动。`ProduceConfig` 只新增末尾带默认值的字段，所有旧构造与 copy 兼容。

## 六、如实限定

⚠️ **真机仍是零证据**：紧凑行在 375px 下是否真的不挤、自定义语气提交后能不能听出差别、
滚动时 chip 高亮跟得顺不顺，都要在 24117RK2CC 上点一次。本轮交付的是「布局收口、
自定义真落地、锚点双向」，不是声音变好。

**本轮不做**：滑块双模改 `BasicTextField`、锚点吸顶、固定音色独立 Screen、v4 剩余两处差额、
V2 目录页 / 迷你条 / 导入通道。各自单独一轮。
