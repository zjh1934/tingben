# 界面形态清单

`docs/screenshots/` 里的图按当前代码画出界面形态，720 宽的独立 PNG，
书名、段数、进度均为模拟数据，**不是真机截屏**。

| 文件 | 页面 |
|---|---|
| `home.png` | 首页：输入框与预留空槽位 |
| `shelf.png` | 书架：书名下进度条跟着制作动 |
| `chapters.png` | 章节目录页：未勾选、双进度条 |
| `segments.png` | 制作中的小块格子与图例 |
| `tasks.png` | 任务页：合成中 / 队列中 / 已完成三段 |
| `mixer.png` | 调音台：九种中文预设音色 |
| `settings.png` | 设置页：代码绘制图标、制作参数板块 |
| `models.png` | 模型页：缺件逐份列全 |
| `player.png` | 播放器：展开态、三态播放模式 |

`docs/images/hero.png` 是 README 首屏横幅，`docs/images/social-preview.png` 可用作仓库社交预览图。
