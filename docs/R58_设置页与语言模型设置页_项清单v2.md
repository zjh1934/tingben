## 0. v1（R55）为什么作废一半

R55 的项清单是按**旧权重 mlabonne Qwen3-4B-abliterated（初版混合检查点）**判的，里头「思考过程 开/关」「快速 / 深度两档」「深度档强制温度 0.6」「原生 32,768 / 未启用 YaRN」这些，全部建立在同一份权重可切换思考模式这个前提上。

用户已决定换成 **Huihui Qwen3-4B-Instruct-2507-abliterated Q4_K_M**，官方明写「仅非思考模式、不生成 `<think>` 块、不需要 `enable_thinking=False`」。**前提没了，项清单必须跟着换** —— 这正是用户反复强调的「设置项要跟模型、官方文档、软件里真传到哪对齐」。

v2 只改项清单与页面归属，不动任何参数默认值、不动 prompt、不动 native。

## 1. 两件事，两个页面

| | 设置页（软件） | 语言模型设置页（标注工序） |
|---|---|---|
| 管什么 | App 本身：外观、数据、日志、后台、关于 | 只在「标注后合成」时用的那份 GGUF 与它的参数 |
| 作用域 | 拨动即写 Prefs，长期默认 | 同左；**不画提交按钮** |
| 入口 | 抽屉「设置」 | 抽屉新增独立项 + 设置页一行「语言模型设置 ›」 |
| 不摆 | 调音台入口、模型参数、模型文件大卡 | 软件外观、日志、后台、声音采样 9 项 |
| 时机提示 | 全页一句「改动立即保存 · 对所有新任务生效 · 正在跑的任务不受影响」 | 同左（复用同一组件） |

三套作用域守恒（R53 §3）：设置页 = 长期默认；制作准备页 = 仅本次；调音台 = 草稿 → 唯一 `commitAll()`。
