## 技术取舍

颜色常量改成**普通 getter**（`private val Bg: Color get() = palette.bg`），getter 内读顶层 `mutableStateOf`；
Compose snapshot 在组合期跟踪这次读取，切主题即重组。**22 个调用点一行未改**，
也不依赖 `@Composable get()` 这类编译器特性 —— 比逐处换 `MaterialTheme.colorScheme.*` 风险低。
`TingbenTheme` 另包 `MaterialTheme`，让未显式着色的 M3 组件（Switch 轨道、Button 默认态）跟随同一套色。
