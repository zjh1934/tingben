# R66 · `1.1.0` 语言模型退场 · 删除联动表

**落地前先列 · 2026-11-06 · 基线 `1.0.0+69`（R65）**

> 用户方向：下一个小版本把语言模型整套拿掉，「语言模型 / 数据标注 / 文本模型」这些说法一律放弃；
> 音频模型保留；左侧抽屉、首页/书架保留。
> 新纪律：**不再要求用户真机验证**；真机样子不确定的，自己画预览图、自己看、自己改，不再把「装完验一下」挂给用户。

## 0. 一句话后果（先认，不藏）

没有语言模型就没有逐段 `{speaker, instruct}`。每章直接走现有的「直接朗读」：原文整段送声音模型，
声音表现只由**调音台的全局音色 + 9 项采样**决定。因此「角色映射 / 按角色换音色 / 逐段语气」一起失效。
调音台、12 维、9 项采样、固定音色、两态试听全属于**声音模型**，一个不动。
