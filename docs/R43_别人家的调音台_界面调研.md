# R43 · 别人给 Qwen3-TTS 做的调音台，界面长什么样

> 纯查验轮：零业务代码、零 CI、零发包。App 仍是 `1.0.0+53`。
> 目的：回答「别人怎么分组、怎么让人操作、哪些控件能照抄」，并把真界面图拿到手。

## 一、三条硬结论

**① 所有项目都把采样参数默认藏起来，把「声音描述」放主位。**
`qwen3-tts-demo` 的源码是 `gr.Accordion("Quality Settings", open=False)`，里面才是 4 个 Slider + 1 个 seed 数字框 [citation:17]；另一篇 WebUI 详解写「右侧参数面板默认收起，点 ⚙ 展开高级设置」[citation:16]；Speech-AI-Forge 也把 Sampling Controls 放进 accordion [citation:13]。官方 VoiceDesign 的 Gradio 更极端——**只有三个区**：文本框、语言、声音描述，加一个 Generate [citation:15]。官方 Playground 的右栏叫「TTS Settings」，第一行就是 **Instructions 多行文本框**，下面才是 Voice 下拉、Speed、格式 [citation:5]。

→ 我们 v3 把 9 项采样收进「更多设置」、身份输入框放首屏，方向是对的；**12 维生成器还该再降一级**，它只是「帮我写描述」的辅助工具，不该和身份框并列。

**② 「保存」和「试听/生成」在所有项目里都是两个独立动作，没有一个要求先试听才能保存。**
亚马逊云那套 WebUI 原话：「修改参数后点击保存，下次生成时自动加载新配置」[citation:8]；Reachy 的同引擎面板是 `All live-apply + persist; restart-safe`，另配一个 preview 播放器 [citation:14]；苹果硅 Gradio 作者说明动机时讲得很直白——「想改单个设置时，不用把整个对话重走一遍」[citation:9]。

→ 你上一轮那句「不试听也可以保存生效」完全成立，别人也是这么做的。v3 已把「提交变更」与两个试听按钮解耦，这条**不用再改**。

**③ 别人界面上的控件 ≠ 真能到我们这个 GGUF 引擎。** 这是本次最该防的坑，下面单列。

## 二、最贴的一张：中文采样参数面板

`01_采样参数面板_Gradio中文.jpg` 是 Gradio 深色面板，逐行是：

| 行 | 控件 | 默认 |
|---|---|---|
| Top-p 采样参数 | 滑块 0–1 + 小数字框 + ⟳ | 1 |
| 采样温度 | 滑块 0–2 + 小数字框 + ⟳ | 0.9 |
| 重复惩罚系数 | 滑块 1–2 + 小数字框 + ⟳ | 1.05 |
| ☑ 子说话者采样开关 | 复选框 | 开 |
| 子说话者 Top-k | 滑块 1–100 + 数字框 + ⟳ | 50 |
| 子说话者 Top-p | 滑块 0–1 + 数字框 + ⟳ | 1 |
| 子说话者采样温度 | 滑块 0–2 + 数字框 + ⟳ | 0.9 |
| 最大生成 Token 数 | 滑块 1–4096 + 数字框 + ⟳ | 4096 |

四个可直接抄的点：

- **中文名在前、无英文路径**，正好是 R42 要的「普通人视图不出现 `qt_tts_params`」
- **滑块 + 小数字框双模**：滑块给人拖、数字框给精确值，比纯输入框好用
- **每行一个 ⟳ 恢复单项默认**，比「组尾一个恢复」更细；这正好是你上一轮要的「一键刷新」范式
- **主说话者 / 子说话者天然两组**，和 Qwen3-TTS-X 的「大师阶段 Talker（决定说什么、怎么断句）/ 工匠阶段 Predictor（决定怎么发声）/ 全局控制」三分法对上 [citation:7]，也和我们 R38 的「主采样 5 / 副采样 3 / 确定性 1」几乎一一对应

⚠️ 默认值别照抄：它 `max_new_tokens=4096`，我们 `qwen.h` 是 2048；`temp 0.9 / top_k 50 / rep_penalty 1.05 / top_p 1.0` 与我们的 `sampling-defaults.h` 一致 [citation:7][citation:13]。

## 三、三态：哪些控件是「别的层」，不能抄

你上轮担心「有些可调、有些不可调」——外部项目正好给出反证材料：

| 别人界面上有的 | 实际属于 | 我们能不能抄 |
|---|---|---|
| 官方 Playground 的 **Speed** 滑块 [citation:5] | 云端 API / 播放层 | ❌ `qt_tts_params` 无此字段 |
| ComfyUI 节点的 `speed` / `cfg_scale` / `emotion` / `dialect` 下拉 [citation:12] | 节点自己实现的后处理与预设映射 | ❌ 引擎字段不存在 |
| Speech-AI-Forge 的 Speed / Pitch / Volume / EQ / 去静音 [citation:13] | 明确叫 **Audio Adjustment（音频后处理）**，与 Generation Parameters 分区 | ❌ 另一层，且我们没接后处理链 |
| CSDN 界面详解里的「情感强度 0–100 / 稳定性 0–100」滑块 [citation:16] | 未见任何源码支撑，疑为其他封装或臆测 | ❌ 不画假开关 |
| Reachy 的**量化档下拉 Q4_K_M/Q8_0/BF16/F32** [citation:14] | 桌面端运行时可换 GGUF | ❌ 我们权重由用户导入、App 内固定 |
| Reachy 的 **Good defaults** 一键降温（temp 0.8 / top_p 0.9 / top_k 20 / rep 1.1）[citation:14] | 纯参数预设 | ✅ 可抄，我们已有 4 组预设 |
| Qwen3-TTS-X 的 4 组推荐配置（稳定 / 完全确定 / 高张力 / 抗电音）[citation:7] | 纯参数预设 | ✅ 我们 4 组预设的来源由此坐实 |

**结论**：`ENGINE / UPPER / LOCKED` 三态不是我们自创，别人的界面里同样混着「生成参数 / 音频后处理 / 运行时资源」三种东西；区别只是他们没标出来。v3 的「三态总览」应该保留，而且要把上面这张表压缩成 2~3 行放进「高级」抽屉，别占正文。

## 四、其余界面形态（可抄的形状）

- **官方 Playground**（`02_官方Playground_TTS设置栏.jpg`）：左侧大文本框 + 4 张预设例句卡，右侧窄栏「TTS Settings」= Instructions / Voice / Speed / 格式，底部 Generate。**主角是一段自然语言，不是参数表**。
- **ComfyUI 节点**（`03_ComfyUI节点_参数平铺.jpg`）：VoiceDesign 节点里 `language / non_streaming_mode / top_p / temperature / max_new_tokens` 与文本框平铺，靠「节点边界」分组，不靠标题 [citation:11]。旁边文档明说 sampler panel「大多数时候不用动，只有输出发机械音才调」[citation:12]。
- **MLX-Qwen3-TTS-WebUI-CN**：5 个 Tab = 自定义语音 / 语音设计 / 语音克隆 / 多人对话 / **设置** ——「设置」是独立顶层项 [citation:22]，印证我们把调音台做成独立页。
- **亚马逊云 WebUI**：多标签页，另有「保存/加载音色」子页把音色提示存成 `.pt` 复用 [citation:8]，和我们「预设库」同思路。
- **qwen3-tts-apple-silicon 的 Gradio**：三模式（Custom Voice / Voice Design / Voice Clone）+ 声音管理 + 可调参数，作者动机就是「改单个设置不用重走整个流程」[citation:9]。这张截图 GitHub 返回 403，只拿到文字描述，如实标注。

## 五、对 v3 预览图的修正建议（待你批准，未动代码）

1. **9 项采样改「滑块 + 小数字框」双模**，每行加一枚 ⟳ 单项恢复默认；保留范围与越界红字。抄 `01` 图，也保留你要的精确值。
2. **分组改名成人话**：「主说话者（怎么说）/ 子说话者（怎么发声）/ 生成长度与确定性」，别用「大师阶段 / 工匠阶段」这种玄名。
3. **seed 补一行**：`-1 = 引擎随机`（qwen3-tts-demo 现成写法 [citation:17]），与「⟳ 换一个 = 新的固定种子」区分开。
4. **12 维生成器再降一级**：收进「帮我写描述」抽屉，默认不展开；首屏主角仍是「已生效身份全文 + 可编辑描述框」。
5. **「三态总览」压缩**：正文只留一句「部分项属于软件层，模型看不到的不会假装有」；完整对照表进「高级」抽屉。
6. **差异/提交屏加一句「不试听也能保存」**，把「提交变更」与试听的关系写死，防再被读成流程链。

**守恒**：R40 唯一提交出口、R41a 两态试听、12 维/9 项/预设/角色/资料能力一个不删；4B 设置、prompt v2、两条制作路径、缓存分桶、native/JNI、前台服务一行不动。
