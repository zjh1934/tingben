# R46 · V1 抽屉壳：联动表与守恒清单

> 队列位置：R34/R35 定案的 V1，连续顺延多轮后的下一轮第一件。
> 用户本轮「继续做」＝按既定节奏推进，不再问方向。
> **只做抽屉壳**：`ModalNavigationDrawer` + ☰ 开抽屉 + 左滑（官方 `gesturesEnabled`）+ 返回键优先关抽屉 + 底栏 3 Tab 收进抽屉一列 + 调音台独立项 + 顶栏/安全区回归。
> **不做**：章节页、按章绿勾、迷你播放条、看书页、沙盒导入、4B 设置沉页尾。

## 2. 9 处联动（R34 原表，逐条对上本轮）

| # | 改动 | 牵动 | 本轮处理 |
|---|---|---|---|
| 1 | 根 `Column` 包进 `ModalNavigationDrawer` | `statusBarsPadding()`、原底栏 `navigationBarsPadding()`、任务条全部变 drawer content | 状态栏 padding 留在 Column；**底栏删掉后补 `navigationBarsPadding()` 到 Column**，否则任务条压系统手势白条 |
| 2 | ☰ 从 `DropdownMenu` 改开抽屉 | `AppTopBar.onMenu: (Int)->Unit` → `() -> Unit`；`MENU_ITEMS` 挪进抽屉 | 菜单副作用（`refresh++` / `modelsFrom`）迁到抽屉 `onNavigate` |

- Manifest 权限、Gradle 依赖、`RefreshStrip`、下拉刷新阈值 `acc > 55f`、任务条上扒/下扒手势

## 4. 抽屉内容（一列，无产品名、无说明文字）

```
书架 / 任务 / 我的音频        ← 原底栏 3 Tab
──────────
设置 / 调音台 / 模型 / 角色音色  ← 调音台是独立一项
```

`NavigationDrawerItem` 的 `selected` 由 `drawerSelected` 给出：
`LIBRARY|PRODUCE→书架`、`TASKS|PROGRESS→任务`、`AUDIO→我的音频`，其余四个一一对应。
顶层用 `chrome.activeTab` 的同一套下标，不另造语义。

## 5. 验收要点

1. ☰ 点开是**一整页抽屉**，不是浮层下拉菜单
2. 从左边缘右滑能开、左滑能关（官方手势，不自写）
3. 抽屉开着按返回键：**先关抽屉**，不直接退回书架
4. 底部 3 Tab 消失，7 个目的地都在抽屉那一列，切换后抽屉自动收起
5. 底栏删掉后，任务条 / 内容不被系统手势白条压住；状态栏下 ☰/＋ 不重叠（R33 回归）
6. 从抽屉进调音台 → 页内「‹ 返回」回到进入前的页面；从设置页进则回设置
7. 9 个 Screen 分支、外部导入落地、通知回跳、`refresh` 全部与 HEAD 一致
