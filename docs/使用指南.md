# 使用指南

> 面向装好 APK 之后的第一步。版本与边界见 [STATUS.md](../STATUS.md)，问题见 [FAQ.md](FAQ.md)。

## 1 · 安装

从 [Releases](https://github.com/zjh1934/tingben/releases/latest) 下载 `app-debug.apk` 安装。
包名 `com.tingben.app`，固定签名，**新版直接覆盖装**，已导入的模型与做好的音频都保留。
要求 Android 8.0+ / arm64-v8a。App 没有 `INTERNET` 权限，安装后不会联网。

## 2 · 导入模型（必做一次）

设置 → **模型**。缺几份就显示几份，逐份点导入，不会把几个文件合并算成一份：

| 文件 | 用途 |
|---|---|
| `qwen-tokenizer-12hz-Q8_0.gguf` | 共用底座，三种模式都要 |
| `qwen-talker-1.7b-voicedesign-Q8_0.gguf` | 描述音色 |
| `qwen-talker-1.7b-customvoice-Q8_0.gguf` | 九种预设音色 |
| `qwen-talker-1.7b-base-Q8_0.gguf` | 参考音频克隆 |

底座 + 至少 1 份模式主文件就能开做。模型文件不进 APK，也不由 App 下载。

## 3 · 把书放进来

- 首页输入框粘贴一段文字 → 点合成，成品落在下方片段列表（能播、能长按删除 / 导出 / 重做）。
- 右上角 **＋** 导入 txt / md / epub；别的 App 里也可以「打开方式 → 听本」。
- 左滑抽屉（或 ☰）看已导入的书；书名下的进度条跟着制作实时动。

## 4 · 定参数与声音

- **设置页**定「怎么做」：语速倾向、段间停顿、失败重试、逐章成品格式与导出位置等。
- **调音台**定声音：描述音色（可存预设，简短描述给你认、详细描述才喂模型）/ 九种中文预设音色 / 参考音频克隆；可先「试听当前改动」再保存设置。
- 制作设置只针对当前这本书，勾章之前不用反复进。

## 5 · 勾章制作

1. 进书 → 章名点进阅读，长按章名出勾选；**全选键再点一下是取消全选**。
2. 勾选后底部菜单只留必要操作，点「制作选中 N 章」。
3. 顺着勾中的章一次做完：每一章的小块做完，**立刻拼成这一章的音频**（拼接中 / 转码中章名上有提示，小格子里转圈），拼完清小块再接着做下一章。
4. 拼好的章音频转成 64kbps 单声道 M4A，校验通过才删掉占地方的内部 WAV；万一没转成功，大文件留着，可在设置页手动另存。

任务统一从**主页右上角任务按钮**看：合成中 / 队列中 / 已完成三段，一条就是一份音频。目录页不再弹任务看板。

## 6 · 听

底部常驻播放条上滑展开、下滑跟手收起。中间是暂停，一个按钮循环切「顺序 → 随机 → 循环」；
右下角打开的是**当前播放的音频列表**，不是整本书目录。通知与锁屏也能控制。

## 7 · 导出

设置 → 音频文件：选导出目录，整本成品按书名分文件夹，各章成品按「章号 + 章名」命名；
同名同大小跳过、变大重写。另有「浏览本机文件」与清理入口。

## 边界

- 不做 PDF / OCR / DRM，不做文本改写与角色切分，正文一个字不改。
- 不拼整本大音频；中间小段拼章后即清，试听临时文件播完即丢。
- 点停止要等当前那一小段推理跑完才真正结束；模型出声本身较慢，不是死机。
