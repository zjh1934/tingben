## 一、根问题解决到什么程度

评审定的调子是「不是参数不够，是生效状态被拆成 4 套语义」。实查是 **5 个写入口**：

| 旧写入口 | 旧时机 | R40 归到哪里 |
|---|---|---|
| ① 身份「保存并生效」 | 立即 | `draft.voice`，由顶部统一提交 |
| ① 九项各自「设定」 | 立即 | `draft.knobs`，行内改值即入草稿 |
| ② 12 维「套用」/ 网格 | 直接覆盖生效 | 只「生成描述 → 可编辑预览 → 填入草稿」 |
| ③ 表演层 / ④ 开关 | 下个任务起 / 长期默认 | `draft.perf` / 两个布尔，统一 `TimingHint` |
| ⑥ 预设「应用」 | 覆盖？无 diff | 「载入为待提交」，不越过状态条 |

**唯一编辑态** `MixerDraft`（`core/MixerDraft.kt`）+ **唯一出口** `MixerCommit.commit()`。
界面里 `Prefs.set*` 六个写入口全部清零（拆包 + 源码级断言双向核对）；`commit` 内只写既有 5 个
`Prefs` 入口，写完重算 `voiceStamp`，旧 WAV 作废仍由 R14 既有机制负责。

顶部吸顶条三段式常驻、不随内容滚走：
`已生效 v4 · 指纹 xxxx ｜ 未提交 N 项 ｜ [查看差异][提交变更]`。
`N` 由 `diff(active, draft)` 逐字段算，**不由控件自己上报**；「查看差异」弹层给
当前生效全貌（instruct 全文不截断）+ 逐项 `旧值 → 新值` + 生效时机；⑦ 降级成「导出与诊断」。

## 二、P0 六条逐条落点

1. **状态条 / 统一动词**：删「设定 / 套用 / 保存并生效 / 应用 / 直接保存生效」五个动词，全页只剩「提交变更」；有未提交时系统返回键先弹「丢弃并离开」。
2. **② 同屏两套写入规则**：12 维与现成网格现在都只「填入草稿」；网格不再 `saveVoice` 直写。
3. **可编辑预览框**：原先只有一行 `拼出的描述（未生效）` 标签，换成随 12 维实时拼串、可手动改字的文本区；手动改过后不被维度选择覆盖。
4. **① 上下对照**：上=已生效全文（只读、浅底）、中=diff 高亮、下=草稿；「清晰自然的中文普通话叙述声…」是 `DEFAULT_IDENTITY` 真值，不是静态说明。
5. **⑦ 降级**：全貌搬进差异弹层；⑦ 只留指纹、并发边界、复制诊断日志。
6. **⑤ 角色**：每行补音色 chip（`P02 温润青年` / 「自定义音色」 / 橙色「未绑定音色」）；映射开且有未绑定时给可见提示「不会静默变成另一个旁白声」；删除改二次确认。

顺带按评审骨架调了默认展开：**身份生成器展开、采样 9 项收起**（原 R38 是采样默认展开）。
`TimingHint` 统一组件复用在 ①②③④，不再各写一种时机说法。
