# 00 · 现行契约

> 每轮动代码前先读这一份。它只写**现在成立的**，不写历史、不写「曾经怎样」。
> 模型侧事实见 `01_音频模型调教逻辑.md`；文件结构见 `02_模型文件结构.md`；界面与交互现状见 `STATUS.md`。

## 主链

```
导入 txt/md/epub → 按章切分 → 三模式供料 → 逐段 WAV（失败即停、可续跑）→ 合并 → 登记每章起点 → 悬浮条按章播放
```
没有文本模型，没有逐段角色与语气切分。**正文一个字不改。**

## 模型契约

- Qwen3-TTS 家族，**1 份共用底座 `qwen-tokenizer-12hz-Q8_0.gguf` + 3 份模式主文件**，各自单独导入、单选启用
- 模式能力以 `app/src/main/cpp/qwen.h` 为准：
  - `voice_design` → `instruct`（自然语言描述，必填）+ 9 项采样；`ref_audio` / `speaker` 被拒
  - `custom_voice` → `speaker` 预设编号 + 语气指令
  - `base` → `ref_audio` 参考音频克隆，拒 `instruct`
- **描述 / 编号 / 参考音频不是同一个字段，也不是互斥开关；是三份不同主权重，切模式要换 talker 文件**
- **三种模式都接通合成**：`voice_design` 用描述（`instruct` 必填）、`custom_voice` 用预设音色编号（`speaker`）、
  `base` 用 24kHz 单声道参考音频（`ref_audio_24k` + 可选 `ref_text`，拒 `instruct`）。
  模式由引擎从 talker GGUF 读出的 `model_type` 决定，界面只供料不决定模式。
- `synthesisBlockReason` 只拦「输入没准备齐」（缺主文件 / 没选音色 / 没导参考音频），不再一刀切拦模式；
  预设音色表读过一次就落盘，没手动挑过音色时自动用第一个，不把合成卡在这一步。
- 任一段两次合成都失败即整次停住：不合并缺段成品、不登记、不标「完成」；已生成的段全留着供续跑。
- 模式选择**不进声音指纹**；`mode_stamp.txt` 单独记录「模式 + 音色编号 + 参考音频指纹」，
  变化时作废这一本已合成的 WAV，避免切模式后跳过旧 WAV 听旧声音。

## 制作契约

- `Producer.start` 恒直接朗读；逐块落盘、断点续传、前台服务 `dataSync` + 通知 + 按块唤醒锁
- 「恒直接朗读」只指流水线档位（正文整段送声音模型、不做逐段改写）；成品列表的 `AudioItem.mode` 显示本次音色模式，由 `TaskInfo.modeId` 映射，回退当前启用模式
- 声音由调音台全局音色 + 9 项采样决定；9 项真到 `qt_tts_params`，上层描述拼成 `instruct`
- `SynthInput` 是主链 / 两态试听 / 声音自检三处共用的唯一装配点；`VoiceRef` 收任意未压缩 WAV，内部下混、线性重采样成 24kHz 单声道再交给引擎
- **任务书签带 `modeId`**：开工时落盘当前模式，旧书签缺字段回退到 voice_design；任务页照实显示档位，续跑按当前模式走，切过模式先给失效预警
- 旧成品统一按「已合成」处理；`legacyVoiceStamp` 双指纹比对保证升级不误删旧 WAV
- 逐章进度只统计**落盘成功**的段；阅读位置记章内段号 + 段内偏移（旧整数兼容读）
- 续跑界面显示的已做段数先与声音、模式两枚指纹对拍；点「继续制作」会作废的 WAV 一律不算已完成
- 导入整本上限 64 MB；超限、内存不足、坏 epub 都给可看懂的话，失败在书架留一张能重试的细卡

## 导航与界面契约

- 无底栏；☰ / 左边缘右滑开抽屉，**6 个目的地**，`Screen` **10 值**，展开时工作页一起推走
- 点书进**单列目录**；点章名默认进阅读，长按勾选，右侧听本章 / 展开小片 / 更多操作
- **单列真值**：成品索引按引擎阶段重读（`running|stage` 变化即重读磁盘），合成完成当轮点亮章进度条与顶部可播汇总；
  逐章进度只归正在跑的这本书，跨书不串；顶部提示条由状态派生，做完不再常驻「正在制作」
- 勾选章后底部小条「调音 › / 合成音频」，**调音在点合成之前，调完直接合成，不要求先试听**
- 进度页四步横排 + 分段看台 8 格；**点格子即播 / 再点停**，无独立播放键、无图例与展开正文；播放走软件内悬浮条，不做独立播放器页
- **任务链三层**：任务页「一本一个任务」（`tasks.json` 按 `bookId` 并存，旧 `task_active.json` 单条兼容读）→ 任务详情按章列状态（成品 / 生成中 / 排队 / 没做完 / 本次没选）→ 点章才进进度页看本章分段看台；合成从目录页启动后直接落任务详情，前台通知点击落任务页
- **进度页带 `(bookId, chapter)` 上下文**：`seg_chapters.json` 记段→章，按章过滤段看台；旧记录没映射文件就显示整次并写明，不画假章内进度
- **音频页按书分组**：组头书名 / 成品数 / 合计时长 / 按顺序播放 / 删除整本（二次确认）；组内每次合成一个成品，试听 / 保存到手机 / 删除；书已删的成品归「未归属的音频」，不静默消失
- 设置页只管软件：主题三档 / 正文字号 / 本机数据 / 诊断与试音 / 后台与关于

## 调音台契约

- **三张模式卡并列、点即切**：描述造音色 / 预设音色 / 参考音频，制作中禁切，不再绕去模型页
- **9 项采样只在「描述造音色」铺开**；另两种模式界面只留一行「沿用全局设置」。
  采样链对三种 `model_type` 都生效（`qwen.h` 无模式条件），功能没删、全局只存一份，只是不占那两页的版面
- 三套输入各自独立保存（描述 / 念法 / 参考音频转录），切模式不互相覆盖；`cvStyle` 不进 `voiceStamp`，
  切模式作废由 `mode_stamp.txt` 单独管，旧 WAV 不误删
- `MixerDraft` 是唯一编辑态，`commitAll()` 是唯一生效出口；两态试听（草稿 / 已生效）点一下即出声
- **数值用普通文字完整显示**，点一下才弹正常高度输入框；细滑块只做粗调，不与数值抢宽。
  9 项采样逐项对应官方字段与默认值，JNI 实收另打 `TTS_PARAMS_APPLIED`
- **结构上不可调的项一个开关都不画**（`speed` / `pitch`、并发、量化档、当前模式下不存在的字段）
- 首屏三张模式卡并列 + 当前模式输入；两态试听**常驻不折叠**，9 项采样按上一条分模式；
  预设音色在音色表之外单独一行「自定义」（`instruct` 可选，与音色叠加），音色编号本身固定不可新增；
  顶栏只留返回 + 有改动时一枚「保存」，不摆说明段、状态徽标、字节数回执、差异弹层与「待提交」话术

## 验收口径

联动表 / 自绘预览先行 → 本地全套自检 + 反向注入 → CI 真 Kotlin 编译 → 核直链 blob 与本地逐字节一致
（**不做拆包比对**）→ 回填 `STATUS.md` / `ROADMAP.md` → 项目文件二次同步带 `[skip ci]`。
静态自检 ≠ 编译过 ≠ 好用；真机零证据不宣称体验结论、不转嫁给用户。

## 我的音频模块（R118）

三层：书 → 章 → 小块。数据来自 `AudioTree.load` 磁盘反推，不另建登记；
章标题由 Pipeline 落 `chapters.json`，旧数据降级为「第 N 章」。
小块唯一 key 是文件绝对路径，多桶段号会重复，不能拿段号当身份。
播放：小块单曲队列 `seg`，整章队列 `chapter:<book>:<ch>`，已有章成品优先。
五项长按操作在 `AudioOps`；拼接 `WavMerger.merge(..., declickMs = 30)`，
段间默认 0ms，只做极短斜坡消爆音，不做真 crossfade。

## 1.1.1 增补

- 主界面锁竖屏。App 不读传感器；系统那个旋转提示来自自动旋转设置，锁竖屏后不再出现。
- 两套通知：制作进度通知（前台服务，点击回任务页、带停止入口）与播放控制通知
  （上一段 / 播放暂停 / 下一段 / 关闭，锁屏可见）。两者都是应用自身通知，不常驻后台服务。
- 播放控制有三处入口：章内小格子、应用内悬浮播放条、通知栏。三者共用 `PlayQueue.state` 一份真值。
- **R158 · 旧硬约束已由用户推翻**：`SYSTEM_ALERT_WINDOW` 按需申请，用于可选的
  系统级悬浮进度控件；「应用内底部常驻条」仍是默认播放入口，两者不混为一谈。
  浮窗不是保活白名单：默认不常显、停止时 `removeView`，不拿它做续跑基础。
- 设置页「后台运行与权限」卡片：忽略电池优化、浮窗权限、应用详情三个标准
  Intent；授权结果一律用官方 API 复检（特殊权限的 result code 不作数）。
  小米深层自启动页无官方稳定 Intent，**不硬编码组件名**。
- **R159 · 续跑确认必须每次回到前台重判**：用户实证「关闭以后重新打开应用
  不一定弹」。禁止 `LaunchedEffect(Unit)` 一次性检查、禁止 `rememberSaveable`
  跨实例记住「已问过」。只要存在未完成任务就给出口（`Producer.pending()`），
  由 `ResumeAction` 决定主按钮；**放宽「看得见」不许放宽「自动跑」** ——
  `Producer.autoResume()` 里的 `autoResumeBlockReason` 守卫必须原样保留。
  设置里「打开软件自动续跑」默认关；开关只作用于 `AUTO` 态，
  `VIEW`/`QUEUE` 仍弹窗。管的是「回到应用自动接着跑」，不是让系统把被杀的
  App 拉起来（Android 不给普通应用这个能力）。守门见 `r149_verify.py`。
- **R158b · 教程不进应用**（用户明确「教程啥的真的不要塞进应用里面」）：
  箭头流程、图文步骤、种子/倍速长解释、成品目录长文一律不进 UI；
  界面只留按钮、状态、空态、隐私告知，以及**删除确认里的后果告知**。
  说明与步骤放沙盒文档（给我和你看的），不进 APK。守门见 `r158_verify.py`。
- 无障碍权限的旧「绝不申请」约束同样清掉，但当前无真实用途，暂不声明
  `AccessibilityService`；将来按真实功能（如朗读其他 App 选中文字）单独评估，
  **不做纯保活拉起**（不是官方白名单，且有合规风险）。
- **权限多 ≠ 保活**。Android 15+ 的 `dataSync` / `mediaProcessing` 各有
  「24 小时内累计 6 小时」上限；长任务靠每段落盘的检查点 + 用户回到应用/点通知
  续跑。前台服务不是永不死的进程。
- 版本真值源是根目录 `version.txt`；Gradle、CI、Release 与三份真值文档都对齐它。

## 1.1.2 增补

- 一本书只有一个主页：单列目录同时承载章节、合成进度与小片、可播成品。
  任务队列在页内就地管理，章级操作收进章多选条；独立页入口全摘，导航收敛为 8 值。
- 返回路径只有一张 `backTargetOf()` 表，顶栏返回键与系统返回键走同一个 `goBack()`。
- 播放只有一套状态：`PlayQueue.state`。底部常驻条点开 `PlayerSheet` 全屏浮层
  （不新增 Screen 枚举值），通知点主体也展开它；五个控制图标由 `PlayIcons.kt` 代码绘制。
- 两态隔离：`PlaybackState.preview` 标记制作中小段与调音台试听，
  这类队列不占常驻条、不进播放器页、不进通知栏，只在原格子就地播停。
- 统一多选：`MultiSelect.kt` 的 `SelectBox` + `MultiSelectBar`，
  章节多选 / 小片多选 / 章级操作共用；长按进态，选完从底部条批量操作。
- 制作链：`TaskResume` 队列按序自动接下一个；开软件对崩溃中断的任务自动续跑，
  手动停止、失败、模型没齐、旧切章口径一律不自动跑。
- 看台骨架只认计划段，音频树只补「这一段已有音频」，切页回来灰格不丢。
- 模型页默认态一屏装得下，低频细节收进一次只展开一项的展开区。
