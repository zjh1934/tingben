# 00 · 现行契约

> 每轮动代码前先读这一份。它只写**现在成立的**，不写历史、不写「曾经怎样」。
> 模型侧事实见 `01_音频模型调教逻辑.md`；文件结构见 `02_模型文件结构.md`；调音台现状见 `03_调音台延迟与一级目录现状.md`。

## 主链

```
导入 txt/md/epub → 按章切分 → 原文整段直接送声音模型 → 逐块 WAV 落盘 → 合并 → 悬浮条播放
```
没有文本模型，没有逐段角色与语气切分。**正文一个字不改。**

## 模型契约

- Qwen3-TTS 家族，**1 份共用底座 `qwen-tokenizer-12hz-Q8_0.gguf` + 3 份模式主文件**，各自单独导入、单选启用
- 模式能力以 `app/src/main/cpp/qwen.h` 为准：
  - `voice_design` → `instruct`（自然语言描述，必填）+ 9 项采样；`ref_audio` / `speaker` 被拒
  - `custom_voice` → `speaker` 预设编号 + 语气指令
  - `base` → `ref_audio` 参考音频克隆，拒 `instruct`
- **描述 / 编号 / 参考音频不是同一个字段，也不是互斥开关；是三份不同主权重，切模式要换 talker 文件**
- **三种模式都接通合成**：`voice_design` 用描述（`instruct` 必填）、`custom_voice` 用预设音色编号（`speaker`）、
  `base` 用 24kHz 单声道参考音频（`ref_audio_24k` + 可选 `ref_text`，拒 `instruct`）。
  模式由引擎从 talker GGUF 读出的 `model_type` 决定，界面只供料不决定模式。
- `synthesisBlockReason` 只拦「输入没准备齐」（缺主文件 / 没选音色 / 没导参考音频），不再一刀切拦模式。
- 模式选择**不进声音指纹**；`mode_stamp.txt` 单独记录「模式 + 音色编号 + 参考音频指纹」，
  变化时作废这一本已合成的 WAV，避免切模式后跳过旧 WAV 听旧声音。

## 制作契约

- `Producer.start` 恒直接朗读；逐块落盘、断点续传、前台服务 `dataSync` + 通知 + 按块唤醒锁
- 声音由调音台全局音色 + 9 项采样决定；9 项真到 `qt_tts_params`，上层描述拼成 `instruct`
- `SynthInput` 是主链 / 两态试听 / 声音自检三处共用的唯一装配点；`VoiceRef` 只收 24kHz/mono/16-bit WAV
- 旧成品统一按「已合成」处理；`legacyVoiceStamp` 双指纹比对保证升级不误删旧 WAV
- 逐章进度只统计**落盘成功**的段；阅读位置记章索引
- 续跑界面显示的已做段数先与声音、模式两枚指纹对拍；点「继续制作」会作废的 WAV 一律不算已完成
- 导入整本上限 64 MB；超限、内存不足、坏 epub 都给可看懂的话，失败在书架留一张能重试的细卡

## 导航与界面契约

- 无底栏；☰ / 左边缘右滑开抽屉，**6 个目的地**，`Screen` **9 值**，展开时工作页一起推走
- 点书进**三列横滑目录**（章节 / 合成 / 可播）；点章名看纯文本
- 勾选章后底部小条「调音 › / 合成音频」，**调音在点合成之前，调完直接合成，不要求先试听**
- 进度页四步横排 + 分段看台 8 格；**点格子即播 / 再点停**，无独立播放键、无图例与展开正文；播放走软件内悬浮条，不做独立播放器页
- 设置页只管软件：主题三档 / 正文字号 / 本机数据 / 诊断与试音 / 后台与关于

## 调音台契约

- `MixerDraft` 是唯一编辑态，`commitAll()` 是唯一生效出口；两态试听（未提交 / 已生效）点一下即出声
- 9 项采样（中文名 · 滑块 · 小数字框 · ⟳）逐项对应官方字段与默认值，JNI 实收另打 `TTS_PARAMS_APPLIED`
- **结构上不可调的项一个开关都不画**（`speed` / `pitch`、并发、量化档、音色编号在 voicedesign 下等）
- 锚点栏依赖 `scroll.value` 像素语义，**不换 `LazyColumn`**
