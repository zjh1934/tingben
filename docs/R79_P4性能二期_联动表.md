## 守恒清单（一个都不许动）

- `Screen` 9 值、抽屉 6 项、`DismissibleNavigationDrawer` 推走联动
- 调音台 `MixerScreen`：`rememberScrollState` / `anchors` / `jumpLock` / `snapshotFlow { scroll.value }` / `animateScrollTo` **一行不动**
- 唯一提交出口 `commitAll()`、两态试听、9 项采样到 `qt_tts_params`
- `ChapterHub.kt` 四处既有 `LazyColumn`、三列横滑、悬浮条形状、`PlayQueue` 单实例
- `Producer.start` 恒 `direct`、前台服务、native/JNI、Gradle 依赖、无 INTERNET、仅 arm64、`<100MB`
- 主题/字号 Prefs、逐章进度、阅读位置、书架首屏、诊断折叠

## 验收口径

1. 本地 `CI=true` 全套自检（含 `check_structure.py` / `r66~r78` 各验证）全绿
2. `r79_verify.py --selftest` 反向注入全拦下
3. CI 真 Kotlin 编译 + APK 闸门（静态绿 ≠ 编译过，run 50/59 的教训）
4. 核直链 blob 与本地 APK 一致；**按用户要求不做拆包比对**
5. 项目文件二次同步 `[skip ci]` 并回读

## 如实限定

- 不宣称卡顿归零；帧率不取自预览图，真机零证据，不向用户索取装机验证
- `LazyColumn` 只覆盖音频页；书架/表单页与调音台保留 `Column`，理由见取舍结论
- release-like 构建会动签名，本轮不做
- 全量 `produceState` 迁移牵动 9 页，单列 P4b
