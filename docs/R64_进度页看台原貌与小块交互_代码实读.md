**⇒ 段 → 原貌的换算：`block_%04d = s.block + 1`。差一必须对上，否则取到上一块。**
**⇒ 一块常切好几段**（R28 注释），多段共享同一份原文是正常的，不伪造逐段独立原文。
**⇒ 多次 attempt** 会有多份文件，默认展示最后一次，允许切换看废稿。
**⇒ direct（直接朗读）路径根本不调 `llmGenerate`**，没有原文；旧 run 被清后也没有。三类都如实写空态，不画空框冒充有数据。
