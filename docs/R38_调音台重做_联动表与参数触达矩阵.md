# R38 · 调音台重做：联动表 + 参数触达矩阵

> 用户三条：「音色身份输入框怎么没有了」「控制台要一一对应官方发布页资料、我去看」「参数调节有没有真正触达」「界面不是给人用的」。

## 1. 先回答「输入框怎么没有了」

**不是删了，是被埋了 + 真值源不同步。** 逐行读 `+47` 的 `MainActivity.kt`：

- 输入框在 `2125-2130` 行，`OutlinedTextField(voiceDraft, label="补充描述（instruct ①，全书固定）")`
- 但它排在 `MixerSection("① 音色身份 · 12 维", ..., defaultOpen=false, ...)` 里 —— **8 个折叠组默认只展开前 2 个**，这组是收起的
- 而且它前面压着 12 个下拉，标签叫「补充描述」，视觉上像 12 维的附属填空，不像主控件
- `voiceDraft = remember { mutableStateOf(Prefs.voiceDescription(c)) }` **没有 key(tick)**：设置页/预设改动后不会刷新，界面显示的和实际生效的可能是两份
- `dimFields`（12 维选择）只在内存里，不落盘、旋转即丢，且必须点「应用为当前音色」才生效 —— 用户选完以为改了，其实没改
- `currentAsPreset()` 存的是 `Prefs.voiceDescription(c)`（旧生效值），屏幕上的草稿不会进预设

**结论：功能在，但人找不到、也分不清哪份生效。** 这轮把它提到首屏固定卡，并把「当前生效」与「草稿」分行显示。

**本轮新增的「真触达」证据**（不只是代码层核实）：
1. `NativeEngine.ttsSynthesize` 包装里写 `TTS_PARAMS` 事件：9 个值 + hash + lang + instruct 长度，三条合成路径（主链 / 试音 / A/B）统一留痕，用户贴诊断摘要就能对照 UI 值。
2. JNI 在 `qt_tts_default_params(&tp)` + 逐字段覆盖之后，打印 `TTS_PARAMS_APPLIED`（`tp` 的实收 9 值 + lang），logcat 可查；拆包验符号在。
3. `scripts/r38_param_audit.py` 解析五处源码生成矩阵，任一字段缺失 / 错序 / 默认值不符即 FAIL；反向注入删掉 `tp.subtalker_top_p = ...` 必须拦下。

## 4. 界面重做（给人用，不手搓）

**抄谁**：
- 参数「元数据 + 说明 + 默认值 + 恢复默认」：PocketPal `CompletionSettings.tsx` + `modelSettings.ts`（`COMPLETION_PARAMS_METADATA` 的 label / validation / defaultValue / step 形状）
- 参数行「label + 一行说明 + 当前值」：OfflineLLM `SettingsScreen.kt:841` `ParamSlider`（Apache-2.0 形状改写，本项目用文本档位 + 精确输入，不引 slider 依赖）
- 折叠卡 / 预设交互沿用本轮之前的 `MixerSection` / `MixerPresetStore`（R36 已抄 IndexTTS / text-generation-webui，不重复造）

**新结构**（首屏固定 + 折叠组，默认展开「采样参数」而不是把主控件藏起来）：

```
[固定 · 不折叠] 音色身份
  当前生效（只读回显，从 Prefs 读）
  ┌ 大输入框（草稿，多行，官方示例占位） ┐
  [保存] [清空回默认]  ← 明确「改动要按保存才生效」
  依据 O1 §Voice Design / O4 §121，自由文本 instruct，不是模型字段

[折叠 ① 默认展开] 采样参数 · 9 项 · 全部到引擎
  每项：中文名 · 官方字段名 · 默认 0.9 · 当前 0.9 · 一行说明 · 触达 ✅
        常用档位按钮 + 精确值输入[设定] + [恢复官方默认]
[折叠 ②] 音色身份生成器（12 维 + 10 网格）→ 只「写入草稿」，不自动生效
[折叠 ③] 表演层 5 项（标「上层 · 下个任务起」）
[折叠 ④] 音频开关 2 项（标「上层」）
[折叠 ⑤] 角色预设
[折叠 ⑥] 预设库（自定义加/删/覆盖）
[折叠 ⑦] 当前生效配置 + 触达矩阵（三态：到引擎 / 上层 / 结构）
[折叠 ⑧] 官方资料索引 O1~O7（名称 + 章节，用户自己去查；App 无 INTERNET，不摆假链接）
[折叠 ⑨] A/B 试听（写明「只换采样参数，instruct 两边相同」）
```

**一并修掉的真 bug**（都属于「控制台不好用」）：
- `voiceDraft` 拆成「当前生效」只读行 + 草稿框，不再假装同一份
- 12 维改成「生成到草稿」，用户看得见它不会自己生效
- `currentAsPreset()` 存当前生效值，并提示「未保存草稿不进预设」
- 设置页「试合成一句」的 `lang="auto"` → `chinese`（与 O1 §167 和主链一致，试音不写缓存，零联动风险）
- `Mixer.snapshot()` 的表演层行标签改「跨书默认（新任务）」，不再冒充「本次」
