# R61 · 点书进「四列横滑目录页」+ 软件内悬浮条 —— 补齐留空的五处

> 纯设计轮：**零业务代码、零 CI、零发包**，App 仍是 `1.0.0+66`。
> 用户原话「我没想好的这些你帮我想想呗」→ 本文替他定五处，每一处都可一句话推翻。
> 通过之后才单开一轮落代码，先列联动表，不夹带 V2 之外的事。

## 一、先把已定的复述钉死（不重开）

点一本书 → **不是**制作准备页、**不是**两个页签，进的是这一本书的**目录页**：同一份按章节拆分好的章列表，平级排成**四列，左右滑切换**。四列用同一批章名，只是状态与能做的事不同。

| 列 | 内容 | 交互 |
|---|---|---|
| 第一列 原始 | 章名 + 右侧一个**可勾选框**（不是三个常驻按钮） | 勾选后**底部浮出小选项条**：去标注 / 直接合成音频 / 标注并合成音频；多选即批量。点章名 → 纯文本看书页 |
| 第二列 标注 | 半透明带色进度条**衬在章名行上**，章名仍可读 | 没标完点章名没反应；标完 → 进这一章标注结果 |
| 第三列 合成 | 灰 = 没合 / 进度条 = 正在合 / 右侧播放暂停 = 完成 | 播放走软件内悬浮条，**不做独立播放器页** |
| 第四列 可播 | 只有「标好且按标注合成好」的章才亮 | 亮行 ▶ 单章播 + 整本顺序控制 |

早先说的「已合成 ✓ 绿勾 + 两个选项卡」被这一版取代；底部那条 = 悬浮条，照听书软件的迷你条形状。

## 二、五处留空，我替你定的

### ① 「直接合成音频」没走标注的章，落点在哪

**第三列亮、可单章播，行上带一枚「未标注」小字；第四列仍灰、不进顺序队列。**

- 硬门槛是用户定的「只有标注后合成的章才进第四列、才变亮」，不能破。
- 但音频确实做出来了，藏起来不讲理，所以第三列照给播放暂停。
- **顺序播放整本只认第四列**，不把没标过的章混进队列——这批章没做过说话人/情绪标注，串进整本会前后不一致。
- 这行给一条「补标注」文字链 → 回第一列预勾 → 走「标注并合成音频」后才进第四列。

### ② 悬浮条里的「目录」具体长什么样

**悬浮条常驻贴底**：封面小方块 + 书名·第几章 + 时间/细进度 + `目录 / ⏮ / ⏯ / ⏭`。位于系统手势白条**之上**，不压手势。

点「目录」→ **从底部弹起半屏抽屉**：只列第四列里亮着的可播章，当前章高亮，点一行切过去播；顶部一行「去书页 ›」回四列目录页。

- 不做第五个页面，也不在悬浮条里再铺一份完整目录真值（避免两处状态对不上）。
- 「目录不是这个，我还没想好」按这个收；若想改成整本目录，只需换抽屉的数据源，壳不用动。

### ③ 第四列除「按顺序播放」外还要哪些控制

**只加三个：按顺序播放 / 从本章起播 / 停止。** 上一章下一章归悬浮条，不重复摆。

「按顺序播放」从上次停的位置起，位置由悬浮条记录，不新造一套。

**明确不画的**：倍速、定时关闭、循环、下载、合并整本 —— 代码里都没有，不画假开关。

### ④ 四列顶部要不要标名字、左右滑要不要小圆点

**要四个文字标签**：原始 / 标注 / 合成 / 可播，当前列紫色高亮 + 下划线；点标签也能切列。**不画小圆点**（跟文字标签重复）。

**手势边界（这条最容易改坏）**：R51 抽屉已经占了「从左边缘右滑展开」。所以**左边缘 24dp 仍归抽屉，内容区内右滑才切列**；顶部标签点击作为兜底。两处不抢，也不跟 Android 系统返回抢。

### ⑤ 第二列「标完点进去」是只读还是能改

**只读 + 右上角「重新标注」**（回第一列并预勾这一章）。不在页内编辑。

理由两条：
- 页内编辑要引入第二套「保存/生效」语义，跟 R40 把五个写入口收成一个 `commit()` 的教训正面冲突。
- 改了标注、旧音频还是按旧标注念的，会静默不一致。所以「重新标注」后**第四列那行立刻变灰**并提示需重新合成，不假装还能用。

## 三、落地前的一个硬前提（不是界面问题）

R34 实查：成品记录只有 `bookId + scope` 文字（如「第 3 章」），**没有章节索引**；也没有「按章已合成」状态。四列的三套状态要真，得给 `index.json` 加章节索引字段并兼容旧数据，标注进度另需一块逐章进度记录。

**这是唯一动数据结构的地方**，单列一轮先做往返对拍（旧数据导入 → 新字段写出 → 再读回），不与界面混做。否则四列会变成「画出来的状态」，正是用户一路在骂的「参数到底有没有真触达」。
