## 0. 先认账：上一轮 U1 做脏在哪

U1 只做了「抽 AppChrome 组件 + 删 ⟳ 刷新按钮 + ☰ 换位置 + 底栏 4→3 Tab」，但：

1. **没做状态栏安全区**。`AppTopBar` 是普通 `Row(padding(vertical=8.dp))`，外层 `Column(fillMaxSize().background(Bg))` 也没有 `statusBarsPadding()`。设备是 Android 16、targetSdk 35+，系统强制 edge-to-edge → ☰ / ＋ 顶进状态栏图标区，跟通知栏重叠。等于把 bug 从左上角搬到了右上角。
2. **下拉刷新还带字**：`RefreshStrip` 里 `"下拉刷新"` / `"松开即可刷新"` / Toast `"已刷新"` 三处。
3. **注释式文案一个没删**：书架大标题 + 副标题 + 重复任务卡、各页大标题、设置项说明、诊断区图例，几十处。

**编译期才暴露的两处连带错误**（静态括号计数抓不到，CI 真编译抓到了）：
- 删掉「其中 N 段是旧缓存」的 `Text` 后，原地留下 `if (verdict != null && verdict.unknown > 0)` 没有 body → `Expecting an expression`。已连同条件行删掉，并在清理脚本里加**悬空 if 通用检测**。
- 任务页结构块多写了一个 `} else {`（原文件下一行还有）→ 解析器把后半页吞进错误作用域，连带 20+ 条 nullable receiver 报错。已修正为交给原文件承接。
