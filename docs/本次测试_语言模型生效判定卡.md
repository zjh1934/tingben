> 先说结论：**你之前听到的「不标注也不错」很可能是 A vs A** —— 标注档一旦校验不过就整块降级成原文平读，和「直接朗读」喂给 TTS 的东西几乎一样。真正被 4B 标成功的块，可能一次都没听到过。

## 0. 开跑前先确认三件事

1. 制作方式选的是 **「标注后合成」**，不是「直接朗读」
2. **思考：关**（思考档会吐大段推理，JSON 被预算拦腰截断 → 必然降级）
3. 用 `听本_试音短篇.txt`（2 块）跑，别一上来整本 —— 手机 CPU 一块 prefill 就要几分钟

## 1. 跑完，看这几行（按优先级）

| 看哪 | 什么值 = 真起作用 | 什么值 = 白跑 |
|---|---|---|
| `ANN_CONTENT` | 「模型 **N** / 补齐 M」里 **N > 0**，且逐条写着〈模型标注〉 | 「模型 **0** / 补齐 M」、整块〈程序补齐〉 |
| 诊断摘要「未采纳首因」 | `-` | `NOT_FOUND_AFTER_0`（模型改写了正文，不是跳标题） |
| `AUDIT_SUMMARY` | 零标注块数 = 0，规则 PASS 数高 | 「零标注 N 块」、逐字覆盖 VIOLATE |
| `ANN_RAW_DUMP` | 原始产出是完整 JSON 数组 | 废话 / 复述原文 / 半截数组 |
| `ANN_BLOCK_END` | `N 条标注 · 通过`，且 level 是 INFO | `0 条标注 · 零标注 ⚠️ 白跑`（WARN） |
| `TTS_INPUT` | `instruct` 里有「压着怒气 / 句尾下沉」这类具体导演指令 | 全是「平稳、清晰地叙述，句间自然停顿」 |

**`ANN_CONTENT` 是最硬的一条**：它记的是**最终进 TTS 的逐条内容**，`text / speaker / instruct` 全文，还标了〈模型标注〉还是〈程序补齐〉。模型吐了 896 字却一条没进合成，这里会直接显示 0 条模型标注。

## 2. 三种结论，各代表什么

- **全是〈程序补齐〉** → 你的直觉坐实了：4B 跑了、手机烫了、电白了，声音一点没变。这不是「不标注也好听」，是**标注根本没介入**。此时先切「直接朗读」听基线（本来就该是这个声音），别再花几小时等标注档。
- **部分模型 / 部分补齐** → 第一次有了真正的 A vs B。去「我的音频」听那几段，和补齐段对比，这才是有意义的判断。
- **全部模型标注** → 这才是第一次听到「标注后的效果」，之前所有版本都没到过这一步。

## 3. 两个会骗人的旧口径

- **`ANN_BLOCK_END ... 通过`**：旧版把「跑完一块」就算通过，降级直读也写通过。`1.0.0+35` 起零标注改 WARN 并写「零标注 ⚠️ 白跑」。
- **进度页「已标注 1/2」**：以前按「跑完几块」算，降级也算标了。现在拆成「模型真标注 a / 直读 b / 续上 c」。

## 4. 新版（含段映射）多两条一眼判定

- 进度页看台上方 **「语言模型是否生效」** 卡：直接说「语言模型已生效：X/Y 段用了模型标注」或「语言模型没起作用：Y 段全是按原文直读」
- 日志 `LLM_VERDICT`：模型 / 直读 / 旧缓存未知 三个数分开
- 看台点开一小格：能看到这一段的**原文全文**、`speaker`、`instruct`、来自第几块第几条、是不是模型标的；还能「重合成这一段」或「重新标注本块」

⚠️ **旧缓存不冒充已标注**：升级前跑出来的段没记来源，一律标「旧缓存，没记来源」，不猜。

## 5. 判完贴给我什么

不用整份日志，贴诊断页「复制摘要」即可，重点四行：
`AUDIT_SUMMARY` / `ANN_CONTENT` / 未采纳首因 / `TTS_INPUT` 前两条。

- 若 `NOT_FOUND_AFTER_0` 仍在 → 模型不是跳过标题，是**改写正文**，逐字契约下救不回来，下一阶段得换成「骨架化标注」（程序切句、4B 只填区间号 + 指令），不再调提示词措辞。
- 若「模型 N>0」但听不出差别 → 那是**音频模型没把 instruct 演出来**，是另一条线（音色分层 / VoiceDesign 漂移），不是文本模型白跑。

---

**一句话**：别用「好不好听」判标注有没有生效，用 `ANN_CONTENT` 里那个 N。N=0 就是白跑，跟好不好听无关。
