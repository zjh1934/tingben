## 6. 如实限定（不藏）

- **真机仍是零证据**，且按新纪律不再向用户索取装机验证。`1.1.0` 直接朗读链路的真机出声、三列滑动手感、375px 三键不压 dock，都只有预览与断言，没有装机结论。
- **dex 里仍有 `AbGate` / `Adoption` / `Annotator` 等类名**：R66 明确「保留但不可达」，避免编译期连锁风险；不是界面文案。主流程还保留语言模型时代的审计落盘前置调用（不加载权重、不进标注分支），物理清理列在 `ROADMAP.md` P1。
- **旧成品兼容**：旧 `index.json`、旧 WAV、旧任务记录仍可读；旧「整本」成品按「已合成」处理，不点亮单章。
- **删除的东西**：语言模型权重（用户已下载也不再导入）、提示词 v2 / v1、语言模型设置页、A/B gate、`MODEL_ID` 诊断、四列里的标注列、五步里的「理解文字」。逐段 `{speaker, instruct}`、角色映射、按角色换音色随之失效，声音全书由调音台统一决定。
- **没做的**：夜间模式 / 正文字号（界面标「待新增」，不画假开关）、逐章精确进度、阅读位置持久化、性能二期。
