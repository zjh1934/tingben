## 先纠正一处项目文件自己的失真

`STATUS.md` R66 方向段写「`Adoption` / `SegPlan` / `VoiceCast` / `NonVerbal` / `Workbench` / `RawDump` / `AuditLog` / `AbGate` 等类型**保留但不可达**」。逐函数实查后这句对一半不成立：

- `VoiceCast` 23 处引用（`CastScreen` / `MixerScreen` / `Prefs.sha` / `Pipeline`）
- `AuditLog` 26 处（`DiagnosticsBlock` 仍可达）
- `SegPlan` 18 处（`ReaderPane` / `Workbench`）
- `Workbench` 4 处（`ProgressScreen` 分段看台）
- `RawDump` 7 处（`DiagnosticsBlock` / 旧分支）

一刀切删类型文件会直接编译断链、并且把诊断与看台一起弄没。所以本轮**按代码实况重划边界**：P1a 只删「调用图里零引用的函数 / 前置调用 / 旧设置键」，其余明确留到 P1b。`STATUS.md` 的「保留但不可达」措辞同步订正为「保留且仍可达，物理删除单列」。
