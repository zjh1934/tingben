## 为什么做

用户已确认两个小弟文件下载中且文件名正确（`qwen-talker-1.7b-base-Q8_0.gguf` 1.94 GB、

## 如实说（不藏）

- **两个新文件还在 App 外**：它们只是在手机下载器里，没导入、没加载、没跑过一块。
  这轮交付的是「能正确识别、能分别导入、能选」的页面与断言。
- **customvoice / base 目前只能导入和选中，不能整本合成**：预设音色要编号、参考音频要音频，
  输入界面属于下一轮调音台。切过去会明确拦住并给一键切回，不假装能用。
- **模式没进声音指纹**：旧 WAV 不会因升级被误删，但也不会因为换模式自动重做。
- **`ttsLoad` 每次合成都重新加载并 `ttsFree`**，所以切模式后下一次合成自然生效，
  界面没有写「卸载重载」这种没实现的动作。
- 真机仍是零证据；CI 全绿只证明编译与断言成立，不证明手感。
- 调音台整页重做 / 提到一级 / 延迟高，按用户要求等下一轮单独引导，**本轮一点没夹带**。
