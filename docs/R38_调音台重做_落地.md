## 1. 调查结论先钉死

**输入框没删，是被埋了 + 真值源不同步。** `+47` 里它在 `MixerSection("① 音色身份 · 12 维", defaultOpen=false)`
内部，排在 12 个下拉后面、标签叫「补充描述」，8 个折叠组默认只展开前 2 个；
`voiceDraft` 初始化没带 `key(tick)`，改动后显示的与生效的可能是两份；12 维选项只在内存里，
选完不点「应用为当前音色」根本不生效；`currentAsPreset()` 存的是旧生效值、草稿不进预设。

**所以不是「功能没了」，是「人找不到、也分不清哪份生效」。**

## 2. 这轮落地（`+48`）

- **音色身份提为首屏固定卡**：「当前生效 · 全书固定」只读回显 + 多行草稿输入框 + 保存 / 清空回默认；
  明确「改动要按保存才生效」；12 维生成器改成「写入草稿」，不再自己偷偷生效。
- **9 项采样逐项对应官方**：中文名 · `qt_tts_params` 官方字段名 · 官方默认值 · 当前值 ·
  一行说明 · 触达状态 · 常用档位 · 精确值输入 · 单项恢复官方默认；默认展开这一组。
- **触达三态标清**：到引擎（9 项采样 + `text/instruct/lang/speaker`）/ 上层（12 维网格、表演层、
  段间静音、拟声、失败重做）/ 结构不可调（量化档、speaker 表、speed/pitch、行内标签）——不画假开关。
- **官方资料索引 O1~O7**：官方仓库 README、VoiceDesign 模型卡、Qwen 官方博客、qwentts.cpp README、
  `qwen.h`、`sampling-defaults.h`、CLI 采样表，按名称与章节列出，用户自行查；App 无 INTERNET，不摆假链接。
  ⚠️ 12 维网格是 ReaderVoice `096b_personas.py`（MIT）的辅助拼装器，**不是官方 API 字段**，文档里写明了。
- **双证据**：`TTS_PARAMS`（Kotlin 传出 9 值 + hash + lang + instruct 长度，三条合成路径统一留痕）与
  `TTS_PARAMS_APPLIED`（JNI 在 `qt_tts_default_params` + 逐字段覆盖之后打印实收值）。
- 顺手修：设置页「试合成一句」`lang=auto → chinese`（与官方 §167 和主链一致，试音不写缓存）；
  `Mixer.snapshot()` 表演层行标签改「跨书默认（新任务）」；预设提示写明「未保存的草稿不进预设」。
- **零 diff**：4B 设置 / prompt v2 / `Producer.start` / `bucket()` / `TaskResume` / 缓存分桶 /
  JNI 签名与参数顺序 / 采样链 / Manifest / Gradle 依赖 / 权限。

## 3. 参数到底有没有触达

链路：`调音台 → Prefs.ttsKnobs / voiceDescription → NativeEngine.ttsSynthesize → ttsSynthesizeRaw(JNI)
→ qt_tts_params tp.xxx → qt_synthesize`。

`scripts/r38_param_audit.py` 解析五处源码生成矩阵，逐字段核对字段顺序、官方字段名、
`sampling-defaults.h` 默认值、`tp.xxx` 赋值、`TTS_PARAMS` 事件、首屏默认展开；
**基线 PASS，9 项逐字段核对通过，5 例反向注入全部拦下**（删 `tp.subtalker_top_p` / 改官方字段名 /
改默认值 / 删事件 / 把采样组藏回折叠）。CI run 48 第 4 步「R38 参数触达矩阵与反向注入」success。

⚠️ **口径**：这是「代码层逐字段核实 + 运行时日志证据」，**不等于**真机上「改参数能听出差别」。
真机 A/B 可辨性仍是零证据。
