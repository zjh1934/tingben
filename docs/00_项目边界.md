# 00 · 项目边界

## 1. 新旧切割

| | 旧项目「墨听」 | 新项目「听本」 |
|---|---|---|
| 目录 | `/data/workspace/moting-android` | `/data/workspace/听本` |
| 源码仓 | `zjh1934/moting-audiobook-android` | `zjh1934/tingben-android` |
| APK 发布仓 | `zjh1934/moting-apk` | `zjh1934/tingben-apk` |
| 状态 | **冻结** `eb8520a`，不删、不改、不再发版 | 从零 |

冻结原因不是「留着以后抄」，是**留作反例**：12 个页面里 9 个是内部页、满屏技术词、每屏 4~7 个按钮、把调试台当产品。
新项目**不引用旧项目的任何 Kotlin / XML / Gradle / workflow / 文档模板**。唯一允许带走的是模型元数据（文件名、尺寸、校验值、已核实地址），因为它属于外部资产，不属于旧代码。

## 2. 硬约束（写进 CI 与测试，不是口号）

- 模型**后导入**，绝不进 APK / 仓库 / Release；APK ≤ 100MB
- App **无 `INTERNET` 权限**，不联网下载模型，不上传任何东西
- 只编 `arm64-v8a`；目标机 Android 16 / 骁龙 8 Gen 3
- 两个模型**串行**、不同时常驻：标注阶段只加载 LLM，合成阶段只加载 TTS，交接先释放再加载
- 正文**逐字不改**（字符级回溯测试，见 `02`）
- 用户第一次听到声音之前，界面不出现任何 `.gguf` 文件名
- 诊断日志默认不含正文、源文件 URI、绝对路径

## 3. 唯一带过来的资产

三个 GGUF，详见 `contracts/model-manifest.json`：

1. `mlabonne_Qwen3-4B-abliterated-Q4_K_M.gguf`（语言模型，可开关思考）
2. `qwen-talker-1.7b-voicedesign-Q8_0.gguf`（TTS 主文件，单音色）
3. `qwen-tokenizer-12hz-Q8_0.gguf`（TTS 配套解码器）

⚠️ **`Huihui-Qwen3-4B-Thinking-2507-abliterated` 不在清单里** —— 那是已弃用的纯思考版，不能关思考，与首版「可靠优先」冲突。

⚠️ 用户贴的 4 个「资源解析服务请求失败」不是坏链：平台解析器扛不住 GB 级二进制；浏览器直接打开即可。第 4 条是别人项目的 APK，与本仓库无关。

## 4. 明确不做（首版）

PDF / OCR / 扫描件 / DOCX / 网页抓取、多角色真换声（voicedesign 物理上单音色）、MP3、封面、字幕、云端同步、模型内置下载器、开机无限续跑、全品牌兼容承诺、预计剩余时间、玻璃拟态/渐变、任何「洗稿 / 改写 / 精简 / 扩写」。

## 5. 不做但记着

多音色（换 customvoice 权重）、WAV/FLAC 导出、倍速、睡眠定时、朗读高亮、批量队列 —— 都是**主路跑通之后**的事，不进第一版。
