## 三、v5 改法（12 屏预览逐屏对应）

1. **头部分两层**：48px 细状态条吸顶常驻（‹ 返回 · 已生效 v4 · 未提交 N 项 · 查看差异 · **提交变更**唯一紫色实心）；试听收成默认折叠的一张卡，展开才出 dock（两态按钮 + 可改试听文本）。写死一句「改完直接提交，不必先试听」——**提交只看 dirty，不依赖试听**（对应 `MainActivity.commitAll()` 现状）。
2. **锚点自动换行**，7 个 chip 两行排完、当前区高亮、零横向溢出（脚本 12 屏 `scrollWidth-clientWidth` 全 0）。
3. **身份卡**：已生效摘要两行 + 「展开全文」；草稿同样摘要 + 「展开编辑」；**只显改动行**（旧→新删除线/绿色），不再两遍全文。
4. **采样默认三组全折叠**；展开后一行一项：中文名 · 滑块 · 小数字框 · ⟳。常用值 chip、人话说明、官方字段都收进该行的 ⓘ，**数字框就是精确值输入**，不再画第二个框。越界时该框变红 + 一行红字。
5. **三态分区**：✅ 9 项真到引擎在主区；⚠️ 12 维 / 表演 / 静音 / 拟声收进「辅助设置」并挂「上层」徽标；🔒 结构上不可调的**不画任何控件**，只在「高级 · 参数对照」列只读表。
6. **固定音色提成独立页**，锚点可直接到，官方三模式对照 + 我们能固定什么 + 为什么没有编号开关。
7. **底部三层**：内容 / dock / 系统栏（手势 24dp、三键 48dp），长列表末尾加 spacer。
8. **删掉全部教操作的注释句**（「想听再展开」「默认不展开」「点一下=合成并出声」等），只留实质信息。

## 四、参数与模型一一对齐（用户本轮硬要求）

数据源：`app/src/main/java/com/tingben/app/core/ParamSpec.kt` 的 `ParamCatalog.SAMPLING`，
官方字段逐字来自随包 `qwen.h:312-320` 与 `sampling-defaults.h`。**9 项全部 `ParamKind.ENGINE`**，
逐字段经 JNI 覆盖；`ParamSpec` 只是只读目录，当前值一律 `Prefs.ttsKnobs`，不产生第二份真值源。

**⚠️ 上层（能改，但模型只看得到文字或音频合并结果）**：音色身份描述（进 `instruct`）、
`lang=chinese`、`speaker=null`（这两项随模式固定，不画开关）、12 维音色网格（写描述的模板）、
朗读档位 / 语速倾向 / 情绪强度（拼进 instruct）、段间静音（WAV 合并插 48B/ms）、拟声表达（改 instruct）。

量化档（运行时换权重）。这几项只在「高级」只读对照里出现，英文官方字段名也只在那里。

## 五、固定音色：官方怎么说（用户连问两轮）

三种模式是**三份不同权重，不是三个开关**：

- **VoiceDesign（当前权重）**：`instruct` 必填，用一段文字描述生成新声音；**没有音色编号、没有音色锁、不吃参考音频**。
- **CustomVoice**：换权重后用 `--speaker` 从 9 个内置编号（Vivian / Serena / Uncle_Fu / Dylan / Eric / Ryan / Aiden / Ono_Anna / Sohee）挑固定说话人。
- **Base**：换权重后用 3 秒参考音频提取说话人身份。

已决定不换模型，所以后两条**在软件里不是可选项，一律不画开关**。
当前能固定的只有「同一段描述 + 同一个 seed + 同一组 9 项采样」全书不变 —— 这是**收敛漂移**，
让每段尽量像同一个人，**不等于官方承诺的跨段完全一致**。这句写进身份卡和独立页，不藏。
