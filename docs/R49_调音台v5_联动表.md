## 二、11 处联动（改之前逐项确认）

1. `MixerScreen` 顶部 `CardBox` 整块替换 → `msg` / `discardAll` / `missing` / `canTrial` / `trialMsg` 五个局部变量的引用位置必须一起搬，否则编译失败。
2. 试听按钮移进折叠区 → `r41a_verify.py` 有一条「两态按钮必须在吸顶 `CardBox` 内」的旧断言，必须同步订正成「细条 3 项 + 试听折叠区 4 项」，**不是放水，是版本演进**。
3. `AnchorBar` 签名多一个 `current: String` → 调用处必须同步传 `activeAnchor`；`jumpTo(it)` 形态保留（r41 断言）。
4. `jumpTo` 内新增 `toggleSection(k, true)` → 该函数必须定义在 `jumpTo` 之前（原代码已满足）；锚点 key 与 `openMap` key 同名。
5. `ParamRow` 整体重排 → `r47_verify.py` 的「ParamRow 与 HEAD 逐行对拍」会失效，改为「R47 滑块双模仍在 + R49 形态由 `r49_verify.py` 逐行核」。
6. `r45_common.canon` 增加剥离 `AnchorBar` 与 `MixerScreen` 整段 → `r46_verify.py` 的 `canon(MAIN)` 全局守恒仍成立（其他业务代码逐行比 HEAD）。
7. 身份卡删掉「已生效全文直铺」→ `check_structure.py` 的 `当前生效 · 全书固定` 字面量必须保留；`音色身份` 仍不能变成 `MixerSection`。
8. `精确值` label 保留 → `check_structure` / `r40_apk_verify` / `r42_verify` 都查这个词面量。
9. `Spacer(Modifier.height(40.dp))` 保留 → `r45_verify` 查；额外 8.dp 追加。
10. 所有 `MixerSection(` 调用的前三个参数（标题 + key + `openMap.contains`）保持原样 → `check_structure` / `r38_param_audit` / `r41_verify` / `r45_verify` 共 6 条字符串断言不受影响；badge 只加在后面。
11. `TimingHint(` 调用数不得 < 9、`MixerCommit.commit(c, draft, n)` 唯一出口、两态 `trial()` 的两种配置拼装、`ParamCatalog.find(it)` 分组循环 —— 全部原样保留。

## 四、参数与模型一一对齐（R48 §4 原样）

`ParamCatalog.SAMPLING` 9 项逐字段经 JNI 覆盖：**seed 42（≥-1）/ max_new_tokens 2048（256~8192）/
temperature 0.9（0~2）/ top_k 50（0~1000）/ top_p 1.0（0~1）/
repetition_penalty 1.05（1~2）/ subtalker_temperature 0.9 / subtalker_top_k 50 / subtalker_top_p 1.0**。
⚠️ 上层：身份描述进 `instruct`、12 维只是写描述模板、朗读/语速/情绪拼进 `instruct`、段间静音 WAV 合并。
🔒 结构上没有：`speed`/`pitch` 数值、并发、codec、speaker 表、量化档 —— 界面不画开关。

## 五、固定音色口径（R48 §5 原样）

官方三模式是三份权重：VoiceDesign（当前，`instruct` 必填，无编号无音色锁）/ CustomVoice（`--speaker` 9 编号）/
Base（3 秒参考音频）。已决定不换模型 → 后两条不是可选项，不画开关、不画上传。
当前能固定的是「描述 + seed + 9 项采样全书不变」＝**收敛漂移，≠ 官方承诺跨段完全一致**。
