# 02 · 唯一主路与验收契约

> **先冻结这份，再写任何界面。** 旧项目最大的错就是先画页面、后补契约。

## 1. 唯一主路

```
打开 App → 书架（我的书）→ 点一本 → 「开始制作」→ 逐章进度 → 做完 → 「我的音频」→ 听
```

- 首屏第一眼：书列表 + 一句「把小说变成能听的音频」；**不是**「还没导入模型」
- 缺模型：只在书卡上就地一句提示 + 一个「去准备」入口，**不拦路、不铺满首屏**
- 一屏一个主按钮；没开始制作之前，不出现导出格式 / 试听 / 保存 / 导出历史
- 进度是「第 3 章 · 已生成 2 分 14 秒 · 失败 1 块」，不是 `token=768 outChars=2666`

## 2. 用户能看见的页面（首版上限 5 个）

| 页 | 作用 |
|---|---|
| 书架 | 书列表 + 导入入口 |
| 书籍 / 制作 | 选章 + 一个「开始制作」+ 逐章进度 |
| 我的音频 | 成品：试听、保存到手机 |
| 准备模型 | 只有缺文件时才去；三个槽位、复制地址、导入 |
| 设置 | 默认只有 3 项：思考开关、导出格式、关于 |

其余全部收进「高级」且默认不可见：试跑、诊断日志、调试页、检查准备状态、事件流、任务包、合成块清单、模型文件名与 SHA。

## 3. 正文逐字不改（字符级契约）

模型输出只能是**结构化导演指令**，不能是改写后的正文。允许：`speaker` / `emotion` / `pace` / `pause_after_ms` / `instruct`。
禁止：改标点、半角转全角、合并空白、补字、纠错、润色、补全、整理、翻译。

验收不是看模型自我声明，而是三条机械测试：

1. 任意标注片段的 `[start,end)` 字符偏移必须能在原文精确匹配
2. 串联全部「正文片段」的字符序列 **== 原文**
3. 模型文本里若夹带正文内容，归一化比较前直接判失败

⇒ 这条规则反向约束提示词：**不能写「润色 / 整理 / 补全」**，只能写「识别角色、语气、停顿并输出结构化指令」。

## 4. 状态机（持久化，不是内存变量）

```
IDLE → IMPORTED → SPLIT → ANNOTATING → VERIFIED → SYNTHESIZING → MUXED → EXPORTED
                    ↑           ↑            ↑            ↑
                 失败/重试   逐块 gate    逐块 PCM     章节边界
```

检查点必须含：源文件 URI（持久权限）、文件指纹、章节顺序、每章起止字符偏移、已完成段落索引、当前音频样本数、模型与参数、输出句柄。
写入语义：临时文件 → `fsync` → 原子重命名。断电后旧章节完整，新章节不完整可删。
**SAF URI 不是路径**，必须 `takePersistableUriPermission()`，否则重启后访问失效。

## 5. 日志分层（旧项目最严重的病）

| 级别 | 内容 | 谁看 |
|---|---|---|
| L0 | 当前章节、已生成时长、下一步、人话错误（「模型文件校验失败」） | 用户界面，默认显示 |
| L1 | 导入/失败原因码 | 长按展开 |
| L2 | 模型加载毫秒、PCM 欠载、编码失败、native 事件 | 工程，不进主界面 |
| L3 | 脱敏诊断快照 | **两步确认 + 字段预览**才可复制 |

L3 默认允许：版本、Android 版本、ABI、构建 hash、模型文件名、字节数、阶段、错误码、PSS/fd、时间戳、短堆栈。
L3 默认禁止：正文、源文件 URI、输出绝对路径、keystore、账号、网络信息。

## 6. 长任务边界

Android 15+ 的 `dataSync` / `mediaProcessing` 前台服务在 24 小时内各限 6 小时，超时必须 `stopSelf()`。
所以首版**不承诺「挂一夜跑完」**：前台服务 + 持续通知承载当前会话，状态落库；进程被杀后下次打开从已完成索引恢复；接近配额时提示「点继续」。
不能只持有 WakeLock 不通知 —— 那是黑盒耗电。

## 7. 首版非功能闸门（是验收条件，不是性能规格）

- 导入 10MB `.txt` 不 OOM
- 100 段模型输出拼接 == 原文
- 飞行模式全程无网络请求
- APK < 100MB、无 `.gguf`、仅 arm64-v8a、无 `android:debuggable`
- 覆盖安装签名不变
- 强杀重启恢复误差 ≤ 1 个已完成片段
- 两次模型热加载不崩溃（**两个 ggml 命名空间隔离的验收**）
- 真机 token 吞吐只记录 P50/P95，**不写「预计剩余时间」**
