## 三、上一段话逐句对照：我 v10 错在哪

### 1️⃣「进度页这个模块也可以收敛进左侧一列的抽屉里面」
- **真实**：抽屉 8 项无「进度」；`chromeOf` 只把 PROGRESS 挂到 TAB_TASKS 组作高亮；「任务」项指向的是**任务中心页**（一整套续跑/放弃/清理功能）。
- **v10 错**：写成「抽屉『任务』项**替换成**『制作进度』，带 42% 徽标，仍 8 项不增项」。这等于把任务中心页整个删掉，续跑 / 从头重做 / 放弃任务 / 最近完成全丢；且代码里根本没有徽标机制。
- **修正**：用户要的是「这一列里给进度一个位置」，不是「把任务改名」。任务中心必须保留。

### 2️⃣「返回书架 和 返回书架下面的这个收起，没什么意义，可以直接不要」
- **真实**：用户位置描述**准确**——`← 书架` 在 923 行单独一行，「收起 ↑」在 924–929 的**下一行右对齐**，再下面才是 931 行手势条。
- **v10 错**：把它们当成同一行的两个装饰按钮直接删，**没看出「收起」是 `expanded` 的唯一开关**，删掉后 975–1140 整块（五步 + 语言模型是否生效 + 分段看台）必须改成常驻，否则功能凭空消失；手势条也失去对象。这跟第 7️⃣ 条「看台不需要折叠」本来是**同一件事**，我拆成两条独立处理了。
- **修正**：删「收起 ↑」+ 手势条 ⇔ 整块常驻，是一组联动，不能只删按钮。

### 3️⃣「百分之几这几个大字不需要」
- **真实**：954 行 34sp 紫色粗体。
- **v10**：这条对上了。但「进度条右侧留 11sp 小百分比」是我自己加的，不是「删大字」的必然结果，进度条右侧原本只有 962 行「已完成 3/7 块」。

### 4️⃣「拆章 理解文字 合成音频 音频整理 横着放 / 前面不一定是状态灯 / 做过的下面有颜色块，没做的没有」
- **真实**：是 **5 步**「拆章 / 理解文字 / **生成声音** / **整理音频** / 完成」，竖排，圆点状态灯在文字**前面**。
- **v10 错 4 处**：
  1. 画成 **4 段**，把「完成」以「不单占格」为由替用户删了 —— 用户没提它，不该替他删；
  2. 文案按用户口语写成「合成音频 / 音频整理」，源码是「生成声音 / 整理音频」，改文案是另一件事，没标出来；
  3. 自作主张给「正在做」加了半透明块 —— 用户只说「做了的**下面**有色块 / 没做的**没有**色块」，**没有中间态**；
  4. 「下面的颜色块」我画成格子下方小色块，但也可能指横排阶段**下面一整条色带**，这层歧义没确认就定了。
- **v10 对的一处**：去掉前面的圆点状态灯，方向没错。

### 5️⃣「语言模型是否生效 跑一次… 后面的这段文案没有必要」
- **真实**：1013–1027 是一张独立 CardBox，标题「语言模型是否生效」+ verdict 结论；`verdict==null` 时才显示「还没落盘段映射；**跑一次「标注后合成」后这里给出结论**」。
- **v10 错**：写成「删兜底句，只留标题 + 一句结论」，把「删一句尾巴」说成「精简整块」，还自己补了「一句结论」。
- **修正**：要删的只是「跑一次…」这个尾巴，标题和 verdict 结论保留。

### 6️⃣「分段看台应该看的是文本模型处理好以后的文字，不是看他处理的哪些文字」
- **真实**：正文**早就在代码里**（1083 行 `s.text` = 最终进 TTS 的那一条），只是藏在「点数字格 → 详情」的二级点击后面；主视觉是 4 色格子 + 图例 + 「第 X 段 · 第 X 块第 X 条 · 模型真标注」这类溯源信息。
- **v10 错**：说成「改成看处理后的正文文字，不再是色块格子」——方向对，但**没说这是把已有详情提出来铺开，不是新增内容**；又自己加了「来源徽标」「标题改『处理后的文字』」。更重要的是，用户「不是看他处理的哪些文字」也可能指的是**图例和溯源元信息**（绿=声音·蓝=模型标…），而不只是「格子」，这层歧义我直接按自己理解定了。

### 7️⃣「分段看台这个板块就不需要折叠起来」
- **真实**：折叠有两层（外层 `expanded` / 内层 `segOpen`）。
- **v10 错**：只让内层常开，没交代外层「收起」删掉后整块（五步 + 语言模型卡片 + 看台）一起常驻，两句话本是一件事。

### 8️⃣「开始停止按钮做的太大了，可以放在进度条左边」
- **真实**：**没有「开始」**。只有 running 时 46dp「停止」、已停止时 48dp「继续制作（从停下的地方接着跑）」；1161 行是空 TextButton 占位。
- **v10 错最大**：画成「42×34dp 小方块（停止 / 继续 / **开始**）」三态，**凭空造了「开始」**，还把两态说成三态。
- **v10 对的一处**：「放到 959 行那条 8dp 进度条左边」方向成立。

### 9️⃣「正在制作 查看进度，这个模块可以完全删掉」
- **真实**：指**跨页常驻任务条 TaskBar**（473–541）：收起态「正在制作 · 3/7 块」+「展开 ↓」，展开后才有「查看进度 ›」(535)。任务中心 1233 行那个按钮叫「**查看实时进度**」，是另一个控件。
- **v10 错**：把任务条和任务中心跳板按钮混成「一个模块」；还主动声明「R61 播放悬浮条原样保留」——用户根本没提悬浮条，是我自己加戏。另外任务条展开还有「去任务页 ›」「去试听 ›」两个分支，删整条会一并消失，我没交代。

### 附带：v10「我替你定的 5 处」全部撤回
「完成不单占格 / 正在做半透明块 / 抽屉徽标替任务条报状态 / 看台标题改『处理后的文字』 / 任务中心收成页底小卡」——其中 3 处建立在上述错误理解上，全部作废。
