# 常见问题

**Q：首页红字说还差几份模型，导进去怎么不对？**
按缺件列表逐份导入。1 份共用底座 + 至少 1 份模式主文件；缺 4 份就列 4 行，不会合并算成 2 份。

**Q：勾完章去哪制作？**
勾选后底部菜单里的「制作选中 N 章」是主按钮。制作参数在设置页定，声音在调音台调；
设置页不会绕过勾章整本开跑。

**Q：做到某一章就停住不动了？**
先看章名上的「正在拼接中 / 正在转码中」和小格子里的转圈。若停在边界，可能是某一段没生成出来、
空间不够或小块重做堵住；从任务页看停下原因。点停止后要等当前那一小段推理跑完（可能几十秒）才结束。

**Q：一章做完会自动拼成音频吗？要等整本跑完吗？**
这一章的小块做完立刻拼成这一章音频，不用等整本。拼完清小块接着做下一章；收尾只补漏。

**Q：整章音频太大 / 找不到 WAV？**
拼好后自动转 64kbps 单声道 M4A，校验通过才删内部 WAV；没转成功会留着大文件，可在设置页手动另存。

**Q：手机上发烫？**
合成是端侧模型推理，本来吃算力。另外旧版有个 bug：已做完的书因旧任务记录没标完成，开机又被自动重跑；
1.1.35 起已拦。若仍发烫，看任务页有没有不该在跑的任务。

**Q：下载链接打不开？**
平台解析器读不了 GB 级二进制会报「资源解析服务请求失败」，用浏览器打开 APK 链接即可，不是坏链。

**Q：日志会记录我的正文吗？**
不会。正文、书名、音色描述都不落盘，只留长度、短哈希与 id；播放失败留纯数值诊断。
