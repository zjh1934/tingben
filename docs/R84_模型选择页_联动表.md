## 3 · 明确不做（不假装做了）

- **不重做调音台**、不把调音台提到一级目录、不动延迟 —— 用户明说下一轮引导。
- **不改 `Pipeline` 的 `instruct / speaker / ref_audio` 传法**：customvoice 要音色编号、base 要参考音频，两者的输入界面属于下一轮调音台。本轮切到这两种模式会**明确拦住并说明**，不静默产出坏音频、不画假开关。
- **不把模式写进声音指纹**：旧 WAV 无模式字段，写进去会让升级后已做好的音频被整体作废（R77 迁移的教训）。
- **不画一键下载**：App 无 INTERNET 权限，只能复制地址 → 浏览器下 → 回来点导入。
- **不做拆包比对**（用户已取消该习惯）；**不向用户索取真机验证**，拿不准的样子自己画、自己看。
