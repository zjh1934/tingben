## 实查到的四个问题

1. **空态没有下一步**：只有一张「还没有音频」卡 + 一句说明，整屏留白。R75 补过文案，但没给可点动作。
2. **双份播放 UI**：跨页 `MiniPlayBar`（细进度条 + 上一条/⏯/下一条/目录）已常驻，
   音频页顶部又整屏铺一张「现在播放」大卡（Slider + 7 按钮 + 倍速 + 关闭）。用户 R61 起明确「播放走软件内悬浮条」。
3. **大卡里的功能不能一删了之**：`Slider` 拖动 seek、`−15s/+15s`、`倍速`、`关闭播放器`、`上一条/下一条`
   在 MiniPlayBar 里**都没有**。直接删卡 = 丢功能。→ 收成默认折叠，不删。
4. **列表行主次不分**：`Button 试听` + `FilledTonalButton 保存到手机` + `TextButton 删除` 三个并列，
   两个实心块抢视线；且没有任何汇总信息。

## 改动清单（只改 2 个文件）
