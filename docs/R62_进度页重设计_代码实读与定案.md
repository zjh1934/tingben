## 二、逐条落到 v10 预览

1. **收进左侧一列抽屉**：抽屉加「制作进度」项，右侧带 `42%` 徽标。展开时右侧工作页仍按 `+65` 的 `DismissibleNavigationDrawer` 推走 240dp，不加遮罩。页内 `onBack` 按钮删除 —— 抽屉随时能切走。
2. **删两套折叠开关**：`923` 返回、`926` 收起文字、`930-950` 手势条三处全删。`expanded` 状态随之退场。
3. **删 34sp 大字**：百分比降为进度条右侧 `11sp` 小字（`42%`），`已完成 12/28 块` 与心跳仍留。
4. **四段横排**：`拆章 / 理解文字 / 生成声音 / 整理音频` 等分一行；原先第五段「完成」不单占格，由进度条走满表达。用户口述里的「合成音频 / 音频整理」对应代码 `生成声音 / 整理音频`，不新增阶段。
5. **色块替代状态灯**：删 `8.dp` 圆点。做过的段下方实心紫块，正在做的半透明浅紫，没做的**只剩灰底、无色块**。
6. **精简兜底文案**：删 `1018` 那句「跑一次…后这里给出结论」；保留标题 + 一句结论。「本次是「直接朗读」，没有使用语言模型」作为判定结论保留。
7. **分段看台改向**：从色块格子（看哪些段被处理）改成**按段铺正文**（看文本模型处理完、送进声音模型的文字本身）：段号 / `text` 全文 / `speaker｜instruct` / 来源徽标（模型标注·程序补齐·旧缓存）/ 合成状态。标题改「分段看台 · 处理后的文字」。
8. **不折叠**：`segOpen` 默认展开，删 `1033` 的「收起 / 展开」开关。逐段试听 / 重合成 / 重新标注本块能力保留在段内展开，不新增第二套数据。
9. **按钮缩到进度条左边**：`42×34dp` 小方块三态（■ 停止 / ▶ 继续 / ▶ 开始），与 `pbar` 同排；不再有整宽 46/48dp 按钮。
10. **删「正在制作 / 查看进度」模块**：跨页面常驻**任务条**整块删除，状态与入口由抽屉项徽标承担。**注意**：删的是任务条，不是 R61 的**播放悬浮条**，两者不是同一组件，播放条原样保留。
11. **任务中心页不再单列**：`1168-1262` 的 `TaskCenterScreen` 里那个整宽「查看进度」按钮本是跳板；抽屉里既有「任务」又有「制作进度」会重复。v10 把抽屉的「任务」项**替换**为「制作进度」（仍 8 项，不增项），断点续跑信息收进进度页底部一张小卡（见 ⑧），「继续制作 / 放弃任务 / 清除失效任务」能力不删、改挂在进度页内。**这是我替用户定的第五处**，可一句话推翻为「任务与制作进度两项并列」。

## 三、我替用户定的五处（可一句话推翻）

1. 横排后「完成」不单占一格（用户数了四段）。
2. 正在做的阶段给半透明色块（用户只说了「做了 / 没做」二值，这里补了中间态的可读性）。
3. 抽屉项徽标代替任务条报状态。
4. 分段看台标题改为「处理后的文字」，副标写「文本模型处理好、送进声音模型的正文」。
5. 抽屉「任务」项替换为「制作进度」，任务中心的断点续跑收成进度页底部一张小卡。
