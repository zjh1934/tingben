# R45 · 调音台 v4 落地联动表（落代码前先列）

**用户本轮口径**：该折叠的就折叠；参数必须跟模型一一对齐、确认可调；不可调的不要摆在能操作的位置，收进后程折叠；固定音色看不懂也要有说明；预览图通过后才能改代码。
**范围**：只改界面层 + 一处 UI 偏好默认值 + 一个设置页入口。真值源、引擎、主链、Gradle 一律不动。

## 一、先把「固定音色」说清楚（官方文档怎么讲）

三种模式是**三份不同权重，不是三个开关**：

| 模式 | 官方输入 | 我们 |
|---|---|---|
| VoiceDesign（当前） | `instruct` 必填，一段自然语言描述生成新声音；无音色编号、无参考音频入口 | 唯一在用的权重 |
| CustomVoice | `--speaker` 从 9 个内置编号选固定说话人 | 换权重才有，界面不画开关 |
| Base | 3 秒参考音频提取说话人身份 | 换权重才有，界面不画上传 |

9 个编号：Vivian / Serena / Uncle_Fu / Dylan / Eric / Ryan / Aiden / Ono_Anna / Sohee。
**结论**：当前权重没有 speaker id、没有音色锁。能固定的只有「身份描述全文 + 种子 + 9 项采样全书不变」，
这是**收敛漂移，不等于官方承诺跨段完全一致**；seed 固定只保证同参数可复现。这句写进界面，不藏。
GGUF 仓库对 base/customvoice 的描述与官方 Python 版有出入，只放进「高级」抽屉，voicedesign 不受影响。

## 二、三态（唯一依据 `core/ParamSpec.kt` 的 `ParamKind`）

- **✅ 到引擎（可调）**：9 项采样 `seed / max_new_tokens / temperature / top_k / top_p / repetition_penalty / subtalker_temperature / subtalker_top_k / subtalker_top_p`，逐字段经 JNI 覆盖 `qt_tts_params`；外加 `instruct` 身份全文、`lang=chinese`、`speaker=null`。
- **⚠️ 上层（能改，但模型只看得到字符串或 App 流程）**：12 维生成器（只是帮你写 instruct 的模板）、朗读档位/语速倾向/情绪强度（拼进 instruct）、段间静音（WAV 合并插 48B/ms）、拟声表达、角色映射、预设库。
- **🔒 结构不可调（不画开关）**：`speed`/`pitch` 数值字段、合成并发、24kHz mono、量化档、speaker 编号表、行内标签。`qt_tts_params` 里物理不存在。

**提交与试听解耦**：`commitAll()` 只看 `MixerCommit.diff()` 是否非空，**不依赖试听**；`trial()` 不写 Prefs、不进 draft、不改指纹。差异弹层明写这句。

## 四、明确不做

- 采样 9 项**不引 Slider**：v4 预览画过滑块 + 数字框双模，本轮保留已落地的「快捷 chip + 精确值输入框 + 单项 ⟳ 默认」等价双模，避免 9 个新滑块把折叠区又撑成清单。若用户要滑块，单独一轮。
- 不把 12 维 / 表演层 / 预设从「⚠️ 上层」提升成「✅ 到引擎」——它们确实不是模型字段。
- 不画 speaker 选择、参考音频上传、`speed/pitch` 开关、量化档下拉。
- 不动 4B 设置、prompt v2、两条制作路径、分桶与续跑书签、native/JNI、前台服务、Gradle 依赖。
