## 提交方式

改用 GitHub Git Data API：`blobs → trees → commits → PATCH /git/ref/heads/main`，提交 `42cbc6041839b7ceabbafb29615040d87ed87c56`。

以远端 head tree 的 blob sha 为基准逐文件比对本地，只提交 **15 改 + 4 删**，自动跳过 **135 条本地 HEAD 落后造成的历史假差异**，没有误删远端文件。首轮 `POST /git/trees` 返回 422 `Must supply a valid tree.mode`，定位为删除条目缺 `mode/type`，补齐后通过。
