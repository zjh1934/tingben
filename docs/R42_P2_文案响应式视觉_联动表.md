11. `TimingHint` 补到角色 / 预设 / 资料三个分区，删「不会自己生效」这类第二套说法

**守恒（逐字节比对 git HEAD）**：`MixerDraft.kt` / `ParamSpec.kt` / `Mixer.kt` / `Prefs.kt` / `Pipeline.kt` / `VoiceProfile.kt` / `ProduceService.kt` / `tingben_native.cpp` / `AndroidManifest.xml` / `app/build.gradle.kts` / `prompt_zh.txt` / `AppChrome.kt`；`MainActivity.kt` 调音台标记之前的业务代码（允许新增 import）。
