## 2. 「看书就是看书」：抄哪半、砍哪半

用户原话：**不要边看边读**。恰好 `ensemble-reads/ReaderScreen.kt` 是「点段落从此处播放 + 当前段高亮跟读 + 底部 PlaybackBar + 睡眠定时 + 倍速」，这一整套**全部砍掉**。

| 保留（V2b 阅读页） | 砍掉 |
|---|---|
| `LazyColumn` 逐段渲染纯文本 | `onPlayFromSeg` / `currentSeg.collectLatest` / `highlighted` 高亮 |
| 中文首行缩进、字号 A-/A+ | `PlaybackBar`（进度/倍速/睡眠定时） |
| 上一章 / 下一章（边界禁用） | `combinedClickable` 长按标注、书签/高亮/笔记 |
| 顶栏「目录」跳回目录、当前章标题 | 书内全文搜索、角色入口 |
| 滚动停 600ms 写 `reading_state.json` | 任何 TTS / MediaSession / 播放控制器入参 |

`controller: PlaybackController?` 这个参数整份删掉——**阅读页不认识播放器**，这是「纯看书」的硬边界。系统 TTS 以后要加，是在迷你条那层加一个 `SpeechRuntime` 接口位，不回灌阅读页。

## 3. 依赖与「指向」映射表（用户点名的那件事）

用户说：「我们加的很多功能都没有依赖，又挪了位置，指向也不一样了。」逐条对：

| 现成件用的 | 我们现状 | 削法 |
|---|---|---|
| `Room`（`ChapterEntity` / `SegmentEntity` / `AnnotationEntity`） | 无 Room，章节是 `Chapter(index,title,start,end)`，正文 `BookStore.read()` | 不建表。`ChapterSplitter.split()` 一次给章节+区间，阅读页 `text.substring(ch.start, ch.end)` |
| `NavController` / `Screen.Player.createRoute(...)` | 单 Activity，`screen` 枚举 + `when(screen)` + `chromeOf()` | 不引 Navigation。新增 `Screen.CHAPTERS / Screen.READER` 两个值，`bookId + chapterIndex` 存成 App 级 `var`，**指向从「路由字符串」改成「两个变量」** |
| `ViewModel` / `StateFlow` / `Hilt` | 无，`refresh: Int` + `remember { mutableStateOf }` | 页面状态留在 `remember`，跨页数据走既有 `BookStore / AudioLibrary / ReadingStateStore`，不引 DI |
| `GlideImage` 封面 / 网络 API / Retrofit | 离线、无 INTERNET 权限、无封面 | 全部删；章名右侧只放「✓ + ▶」 |
| `material-icons-extended` 的 `Icons.*` | 项目约定用文字字形（R32 定过） | `☰ / ＋ / ▶ / ⏯ / ✓ / ‹ / ›` 继续用文字，不加依赖 |
| `MediaSession` / `AudioPlaybackService` / ExoPlayer | 已有单例 `PlayQueue`（StateFlow），音频页与看台共用 | 迷你条**只订阅 `PlayQueue.state`**，不碰播放器内核 |
| 包名 `com.ensemblereads.* / com.readervoice.* / com.example.owlread.*` | `com.tingben.app` | 移植时全量改 package + import；**文件挪进 `ui/` 后，`MainActivity.kt` 的 `when(screen)` 必须同步加分支**，否则编译能过但点书白屏 |

**「指向」具体会变 5 处**（这就是不能贴过来就完事的原因）：
1. `LibraryScreen.onOpen` 从 `screen = PRODUCE` 改成 `screen = CHAPTERS`，`bookId` 仍是同一个变量
2. `AudioLibrary.AudioItem` 加 `chapters: Set<Int>`（绿勾唯一的数据来源），`index.json` 读写 + 旧记录兼容
3. `chromeOf()` 加 2 个映射；`Screen` 9 → 11 个值；`BackHandler` 基准仍是 `LIBRARY`
4. `PlayQueue.setTracks()` 的 tracks 语义：现在是**成品 WAV 列表**，迷你条「下一章」要改成按「当前书的章节 → 对应成品/段」查表，不能凭 `index+1`
5. 外部「打开方式 / 分享」落地、通知 PendingIntent 回跳，都得允许落在 `CHAPTERS`

**一行不碰**：native / prompt v2 / `Prefs` / `Producer.start` 签名 / `bucket()` / 缓存分桶 / 任务书签 / `ProduceService` / 4B 设置 / Manifest 权限 / Gradle 依赖。

## 4. 书架那一层（用户最后那句「哎，书架」）

- 书架**只放原书**（R18 已定），不因做了一章多一本
- 点书卡 → **目录页**（不再是制作准备页）；制作入口移到目录页右上角一个图标
- 书卡/目录页顶部显示「继续阅读 第 X 章」：数据来自 `reading_state.json`，不是制作进度
- 目录行：`章名` + 右侧 `已合成 ✓`（`AudioLibrary.chapters`）+ `▶`（有成品才可点）；点行 = 进**看书页**，不是直接播放
- ▶ 才走 `PlayQueue.setTracks/playFrom`；没成品的章显示「制作」，点了进制作准备页并预选该章
