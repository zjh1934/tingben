## 2. 现状的三个真问题（改前实查）

1. **平铺**：+40 的 `MixerScreen` 是 5 张 `CardBox` 一路往下堆，只有「音色身份 / 采样 / 边界」三块有 `if(open)`，预设、角色、A/B 全摊开。
2. **预设不能自定义**：`SamplingPresets.ALL` / `VoicePresets.ALL` 都是编译期 `listOf`，用户只能「应用」，不能加、不能删、不能改名、不能存当前配置。
3. **角色预设空**：`VoiceCast.load()` 在没有标注结果时返回空表，调音台里压根没有角色区，用户看到「角色=0」。
4. **参数没控全**：`max_new_tokens` 只在设置页有，调音台 9 项只画了 8 项；12 维只是 12 行**说明文字**，不能逐维选；表演层 5 项在调音台只读；拟声 / 角色映射开关只在设置页。

## 3. 新设计（8 个折叠组，默认只展开前 2 个）

| 组 | 默认 | 内容 |
|---|---|---|
| 当前生效配置 | 展开 | 18 行只读快照 + 采样链 + 复制进诊断日志 |
| 预设库 | 展开 | 4 内置 + 用户自定义；应用 / 删除 / 存为预设（同名覆盖）/ 恢复上游默认值 |
| ① 音色身份 12 维 | 收起 | 12 个 `SettingOption` 逐维可选 + 实时拼出的 instruct 预览 + 自由描述 + 10 条现成网格 |
| ② 采样 9 项 | 收起 | seed / **max_new_tokens** / 主 temp·topK·topP / rep / 副 temp·topK·topP |
| ③ 表演层（仅本次） | 收起 | 档位 / 语速 / 强度 / 段间静音 / 失败重做；标「下个任务起，正在跑的不受影响」 |
| ④ 音频开关 | 收起 | 拟声表达、角色映射（读写 `Prefs` 同一入口） |
| ⑤ 角色预设 | 收起 | 4 张内置卡 + 增删改 + 套用网格 + 扫描标注角色 |
| ⑥ 合成边界与覆盖核对 | 收起 | 30 项可编辑 / 5 项只读 / 5 项结构不可控，一张表说清「能控的通通都在」 |
| ⑦ A/B 试听 | 收起 | 同句同 instruct，A=当前 / B=任选预设（含用户自定义），不写回长期默认 |

**不是平铺的证据**：`MixerSection` 用 `rememberSaveable(key)` 记住每组展开态，旋转屏幕不丢；8 组共用一个组件，不是 8 份手写 `if(open)`。没引 `AnimatedVisibility` 是因为 `app/build.gradle.kts` 里没有 `compose.animation`，为一个折叠动画加依赖违反「平台自带能力能覆盖时别引重型依赖」。

**最容易翻车的一处**：`defaultPerf` 是「以后新建任务的默认」，不是「当前跑着那本书的本次值」。若把它塞进 `Producer.start` 或 `TaskResume`，正在跑的任务会风格断层。所以只改了制作页初值与「本次恢复默认」两行，续跑路径原样保留——`r36_verify.py` 里有反向断言专门盯这条。

## 5. 验证

- `scripts/r36_apply.py`：4 处切片每处强制命中 1 次，否则整体不写回。
- `scripts/r36_verify.py`：正向符号（折叠定义形态、9 项采样逐项、5 项表演、12 维、预设 CRUD、角色 seed、作用域、守恒）+ **7 组反向注入**（删折叠定义 / 删状态保持 / 删预设保存 / 恢复第二套采样 / 删 max_new_tokens / 删角色 seed / A-B 写回默认，必须全 FAIL）+ 6 组预设 JSON 往返对拍（含同名覆盖、非法字符名、空名、坏 perf 宽容、未知枚举）。
- `scripts/check_structure.py` 追加 R36 段，CI 真编译前先跑；并拦「为折叠动画引新依赖」。
- 拆包硬验：版本号、CRC、7 个 arm64 `.so`、无权重、无 INTERNET、dex 新符号、旧设置页文案零残留。
- **固定直链交付前必须核 blob 与本地 APK 逐字节一致**（R33 踩过直链滞留 +41 的坑）。

> ⚠️ 真机仍是零证据：预设好不好用、A/B 能不能听出差别、4 张内置角色卡是否合口味，都要在 24117RK2CC 上点一次。这轮解决的是「看得见、调得动、能存、能复盘」，不是「声音已经变好」。
