# U1 · 全局壳落地（1 轮，只改表现层）

> 用户原话：「这一轮就改 UI 架构，不要给我软件改坏掉啊。」
> 所以本轮的取舍是：**架构真抽一层，数据流一行不动**；不追求把 R32 表里 U1~U4 一口气做完。

---

## 1. 改了什么

### 新增 `app/src/main/java/com/tingben/app/AppChrome.kt`（194 行）

应用级「壳」层，抄 Now in Android 的 `NiaAppState` / `TopLevelDestination` 思路：顶层目的地集中定义，页面只负责内容。

| 件 | 作用 |
|---|---|
| `TAB_LIBRARY / TASKS / AUDIO / NONE` | 顶层目的地常量；NONE = 设置域不高亮任何 Tab |
| `ChromeSpec(title, activeTab, showImport)` | 一屏的壳规格 |
| `AppTopBar` | 左侧 ☰ 设置入口 + 当前页标题 + 仅书架显示 ＋ 导入 |
| `AppBottomBar` + `AppTab` | 3 个顶层 Tab |
| `RefreshStrip` | 下拉刷新条，从书架页抽出来变成可复用件 |

**零业务逻辑**：不认识 `Screen`、不碰 `refresh` 计数器、不碰任何数据层。颜色由调用方传入，不复制一份设计常量（避免两份真值源）。

### 改 `MainActivity.kt`（+48 / −73）

- 顶栏：删产品名「听本」、产品定位小字、「⟳ 刷新」文字按钮；改成 `AppTopBar`
- 底栏：4 Tab → 3 Tab；「设置」移到左上角 ☰，点它仍 `screen = Screen.SETTINGS; refresh++`
- 新增 `chromeOf(Screen)`：**全 App 唯一的「目的地 → 壳规格」映射**，取代原先散在顶栏/底栏的 4 处 `screen == ...` 判断；顺手修掉 `Screen.CAST` 从来不高亮任何 Tab 的老问题
- 书架下拉刷新：手搓手势抽到 `RefreshStrip`，阈值 `acc > 55f` 一字未改，提示文案删掉「或点右上角 ⟳ 刷新」
- 修真 bug：`BookStore.delete(...)` 之后补 `onChanged()`（原来删书后列表不刷新）

### 改 `scripts/check_structure.py` / 新增 `scripts/r32_verify.py`

CI 自检加 U1 守恒断言；反向验证脚本注入 11 种回归，逐一确认断言真的会拦。

6. 恢复旧文字刷新按钮 → 拦

11. KDoc 注入注释收尾符 → 拦

**反向验证反过来抓出了我自己的 4 个假绿**，都已修：
- `chromeOf` 首版注入用例没真删分支 → 用例重写
- 阈值断言 `"acc > 55f" in chrome_src` 被**我写在注释里的同一个词**骗过 → 改成精确匹配代码行 `if (acc > 55f) {`
- `AppBottomBar(` 断言被注释行 `// AppBottomBar(` 骗过 → 改成行首正则
- **真漏洞**：原 R20 KDoc 检查用 `mask_strings` 后的文本，而 `mask_strings` 会把 KDoc 里提前出现的 `*/` 当闭合符抹掉 → 对 `KEY_*/DEFAULT_` 这类注入**恒不触发**。已补一条基于原始文本的 KDoc 行级检查兜底。

**git diff 范围**：仅 `MainActivity.kt`、`check_structure.py`（已跟踪）+ 新增 3 个文件。核心数据层 / native / 服务 / Manifest / Gradle 全部零 diff。

⚠️ **本地没有 gradle-wrapper.jar 也没有 Android SDK，无法本地真编译。** 真编译由 CI 承担；静态自检 ≠ Kotlin 编译通过，这条不松口。

## 4. 本轮明确没做（不冒充做了）

- 下拉刷新**没有**换成 Material3 `PullToRefreshBox`，也**没有**推广到任务/音频/进度页 —— 换滚动容器会牵动 4 个页面，放 U2。现在只有书架页有下拉刷新，行为与旧版等价。
- 书架页的大标题/小字、任务卡上扒下扒、粘贴框、图标化操作、删除确认弹窗 → 全是 **U2**，本轮一个没碰。
- 设置页/制作页/任务页/音频页的注释式文案清理 → **U3**。
- 调音台一级入口 → **U4**（这轮它仍在「☰ → 设置 → 第一张卡」，且数据层完好、dex 符号全在）。
- 性能页、无障碍/浮窗保活 → 已删，不复活。

## 5. 用户视角的变化与风险

| 变化 | 风险 |
|---|---|
| 顶栏不再显示产品名和定位 | 无功能影响 |
| 「⟳ 刷新」按钮没了 | 下拉刷新仍在；若用户只习惯点按钮，会短暂找不到 → U2 会统一 4 页下拉 |
| 底部「设置」Tab 没了 | 改走左上角 ☰；`Screen.SETTINGS` 仍可从各页「返回设置」到达，系统返回键仍回书架 |
| 设置域 4 页底栏不高亮 | 有意为之（它们不属于任何顶层 Tab），顶栏标题会显示当前页名 |
| 删书自动刷新 | 修 bug，纯增益 |
