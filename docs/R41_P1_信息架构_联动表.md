## 三、6 条落地形态

**7 锚点 + 记住展开**
- 新增 `AnchorBar`：一行水平滚动 chip `身份 | 采样 | 表演 | 开关 | 角色 | 预设 | 资料`，点一下滚到该区（位置由 `onGloballyPositioned { positionInParent().y }` 记录，展开/收起后自动重算）。
- `MixerSection` 改受控：展开态存 `Prefs.mixerOpenSections`（逗号分隔 key），**不进 `voiceStamp`、不进 diff、不碰任务书签**；默认只展开「身份生成器」。

**8 编号统一**
- 去掉全部圈码与 `①~⑧`，只用分区标题；`O4/O5/O6`、`只读·O1~O7` 这类元信息全部收进「参数触达与官方资料」折叠区。
- 「导出与诊断」并入资料区底部，8 区收成 7 区，长页面少一屏。

**9 九项紧凑表**
- 三组：主采样 5（主 temperature / 主 top_k / 主 top_p / repetition_penalty / max_new_tokens）、副采样 3（副 temp / 副 top_k / 副 top_p）、确定性 1（seed）。
- 共用 `ParamRow`：一行 label + 范围，一行说明，一行快捷 chip，一行精确值输入；组尾一个「恢复本组官方默认」。**组尾不再放提交按钮**，全页仍只有顶部「提交变更」。

**10 精确值**
- `ParamSpec` 加 `min / max / unit`（唯一范围来源），`rangeLabel` 由它生成；`validate()` 抄 PocketPal 返回可显示文案。
- 输入框 `value = 用户草稿 ?: spec.read(draft.knobs)`，**默认带出当前值**；越界 `isError` + 红字；`KeyboardOptions(Number, Done)` + `KeyboardActions(onDone)` 规范化回读；chip 点后回填输入框并清掉旧草稿，避免「两处同时强调」。

**11 预设 diff**
- 「载入为待提交」→「对比并载入」：先弹层逐项 `当前生效 → 该预设`（复用 `MixerCommit.diff`，不写第二份拼串），确认后才写 draft。
- `chips()` 补主/副采样、rep、max、seed、身份字数、维数；空名与 `untitled` 禁止保存（Store 层也拦）；已有 `untitled` 给「重命名 / 删除」；删除加二次确认。
- `MixerPresetStore.rename()` 复用 `save/delete` 抽出的 `writeAll()`，`.part` 原子落盘不变。

**12 音色选择器合并**
- 新增共用 `VoicePicker`：搜索框（编号/名称/摘要过滤）+ 「最近使用」横向 chip（`Prefs.recentVoices`，最多 4 条）+ 过滤后的网格列表。
- ② 的网格、⑤ 的「初始音色」下拉**都换成同一个组件**，只是 `onPick` 不同（② 填入身份草稿 / ⑤ 设新角色初始音色）；点任一音色写 `pushRecentVoice`。
