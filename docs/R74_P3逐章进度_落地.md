## 对着代码查出来的三件真问题

1. **逐章进度本来是假的**：`chapterStates` 用 `done/total` 算一个整本比值，再摊到每一章，界面还写「整本进度 43%」。`Producer` 只有整本 `done/total`，`Chunk.chapter` 在 `flatMap` 成段后丢失。
2. **三列却写着四列上界**：`derivedStateOf` 仍 `coerceIn(0, 3)`，而 `HubTitles` 只有 3 个、分发是 `repeat(3)`。滑到「可播」时高亮会跑进不存在的第四列。
3. **旧说法没清干净**：`AnnColumn` 死函数还挂在文件里，含唯一可见旧词「已分段」；`ChapterUi` 还留着 `annotated` / `unannotatedAudio` 两个无人使用的字段。R66/R68/R73 都声称清过，这一页漏了。

## 落地内容

- **真值链**：`Chunk.chapter` → 切段时按块补 `segChapter` → 每章分母 `perChapterTotal` → 每段 WAV 落盘成功才 `perChapterDone[ci]++` → `chapterSnapshot` 随 `emit` 进 `Progress.chapterProgress` → `chapterStates` 只认 `chapterProgress[i]`。
- **失败段不算完成**：用 `segStart = wavs.size` 判定，续跑跳过已有 WAV 也算完成；失败沿用上一帧快照，不回退成 0。
- **界面**：合成列写「本章已生成 N%」；没上报数据的章是 `null`，灰 +「等待中」，**不再摊整本比值**。
- **阅读位置**：新增 `core/ReadingState.kt`，`filesDir/reading_state.json` 存 `{bookId: chapterIndex}`；打开看书页与上下章都写，目录页顶部一条细提示「上次读到 第 N 章 · 章名 / 继续 ›」，制作中不显示。写失败静默，不影响看书。
- **同页清理**：删 `AnnColumn` 与两个死字段、改头部注释、`coerceIn(0, 2)`。
